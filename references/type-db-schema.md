# 数据库 schema（物理模型）

**最适合**：**物理层** schema——真实表、真实 SQL 类型、真实约束与索引、列到列的外键。它是把 DDL 画 readable 的东西：迁移评审、真实库的结构 review、任何「列类型或 ON DELETE 行为本身就是要点」的场合。

**不做领域建模。**[ER / 数据模型](type-er.md)是实体层：关系线连**盒子**、带基数、字段平铺，谈概念和领域用它。数据库 schema 是列层：FK 连线锚定到**具体列行**——ER 给不了的能力，也是这个类型存在的理由。判据一句话：谈「删一行会发生什么」用数据库 schema；谈「订单到底是什么」用 ER。

**图内标识符不翻译**：表名、列名、类型、约束、索引名、schema 名都是源库里的代码，原样落图（`public.orders`、`customer_id`、`numeric(12,2)`）；说明性文字（溢出行、图例、标题）用中文。

## 布局惯例

### 表盒

- **头带**：`schema.table` 走节点名档（sans 14px · 600），右侧矩形类型角标（`rx=2`，不许药丸形）写 `TABLE`（拉丁 eyebrow 档 mono 8px）。头带淡染 `ink @ 0.05`；头带下一条发丝线分隔（`ink @ 0.10`，看板列头同档）。
- **列行**：固定 **24px** 行高——连线锚定全靠它可预测。每行：列名 sans 12px 居左，SQL 类型 mono 9px `muted` 居右（`uuid`、`text`、`numeric(12,2)`、`timestamptz`），中间约束芯片 20×12（`rx=2`，描边 `ink @ 0.40` · 0.8px，mono 8px）：`PK`、`FK`、`UQ`、`NN`。偶数行交替背景 `ink @ 0.02` 提高可扫性。
- **溢出行**：列数超预算时，最后一行写「另有 N 列未显示」（sans 12px `muted`）。**绝不静默截断**——截了不说等于撒谎。
- **索引区**：可选的末段，发丝线分隔 + `INDEXES` eyebrow（mono 8px）+ 索引名（mono 9px）。只列讲故事的索引，不把全表索引搬上来。
- 表盒描边 `ink @ 0.40` · 1px，`rx=6`，宽 240；相关表靠近排布，让大多数 FK 是短线。

### 外键连线——定义性规则

每条 FK 边起于**源列行的垂直中心**，止于**被引用列行的垂直中心**，正交圆角肘走线（r=8，SKILL §8）；**短位移**（起终点纵向差 < 32）用双 Q 连续 S 弯，不要硬塞「Q-V-Q」三段。每条边以 mono 8px 标注引用动作——`ON DELETE CASCADE`、`ON DELETE RESTRICT`、`ON DELETE SET NULL`——配 paper 不透明遮罩、与线 6–10px 净空。

24px 行高保证：两条 FK 附着在同一表边的**不同行**时天然 ≥12px 间距——行距本身就是扇出。两条以上 FK 附着**同一行**（如两张子表都引用同一主键）时，附着点绕行中心 **±8px 对称偏移**——每点都在 24px 行带内、与邻居 ≥12px，每条线仍然可独立追。三条以上竖井路线互距 ≥12px，别并成一股电缆。

### schema 分组

非默认 schema 的表装进分组盒（`rx=8`，`ink @ 0.02` 填充，`ink @ 0.20` 描边虚线 `4,4`），左上角 schema 名（mono 8px eyebrow 档）。组盒先画，表盖其上。组内表的外键线必然穿一次组盒边缘——让它垂直向短穿，不要斜切长行。

### 焦点规则

2 个 accent 是：(1) 唯一的破坏性 FK（`ON DELETE CASCADE`）——边和它的标签算**一个**，因为带标签的边是一个东西；(2) 被级联删除波及的表——**只染头带**（`accent` 淡染），绝不染整盒。图上其余一切不 `accent`。

schema 里没有破坏性 FK，就没有焦点元素。留白不硬造——不为了有焦点去提拔一张随便的表。

## 复杂度预算

最多 5 张表、每表 8 个列行、6 条 FK 边、2 个 accent 元素。超预算 → 画**子系统**不画全库，并在标题里说明。一张 schema 图是关于某个子系统的论证，不是 `\d+` 的转储。

## 反模式

- **每张表每列全画。** schema 图是论证，不是数据库 dump。
- **FK 连盒子到盒子。** 那是 ER 的画法——锚不到列行就没有用这个类型的理由，改用 ER。
- **缺 SQL 类型。** 类型是半张图的内容，省了图就空了一半。
- **无标注的 FK 边。** `ON DELETE` 行为是 review 的人要找的东西，线画了不标注等于没画完。
- **约束芯片铺满每一行直到变成噪音。** 芯片是给关键列看的，不是每行的仪式。
