# 象限图（Quadrant）

**最适合**：优先级排序（影响力×工作量）、定位（触达×频次）、组合地图、2×2 决策框架。

## 布局（标准象限）

- 2×2 网格；轴 = 1px `ink` 十字过中心，单端箭头（上、右各一枚）。
- **轴标签极简**：每个箭头尖端外**一个词**——不放箭头符号（↑→）、不放括号注释、不放"高/低"前缀。中文 2–4 字：sans 12px · 0.3em · `ink`。位置在尖端外侧：上端 `text-anchor="middle"` 居中约 12px、右端 `start` 约 12px；箭头短到离 viewBox 边留 60–80px 给标签呼吸。
- 不在轴中点放任何标签。
- 角标：四角动作词（优先做 / 重点投入 / 顺手做 / 暂缓），sans 12px · 0.3em · `soft`，横轴两侧 ±12px 对称放置。
- 条目 = 小圆点 `r=4` + 标签：sans 12px · `muted`，标签离点 8–10px，**不压轴线**。
- 焦点：唯一"先做"条目（通常右上）用 `accent`——点 + 光晕（`r=8`，accent @ 12%）+ 标签 600。
- 条目 ≤12；再多就分组或拆图。

## 反模式（标准象限）

- 四个象限填四种颜色——位置 + 标签已经足够，颜色是噪音
- 条目压在轴线上（象限归属含糊）
- 缺轴名
- 条目标签 <10px
- 双焦点（两个焦点色点 = 没有焦点）

## 顾问式变体（2×2 情景矩阵）

标准象限的**布局变体**——同一套默认皮肤（纯白纸面、serif 标题、焦点色焦点）。语法变了两个地方：轴承载的是**区间**而非刻度；格子里放的是**命名情景**而非定位点。

**用于**：框定四种未来、原型或战略选项，横跨两个独立驱动因素——经典情景规划、定位框架、2×2 战略页（BCG / 麦肯锡领地）。读者应该带走四个有名字的赌注，而不是一团点云。

**不用于**：优先级排序、密度图、任何"格内位置本身承载含义"的场景——那是上面的标准象限。

### 变体到底变在哪

| 动作 | 标准象限 | 顾问式变体 |
|---|---|---|
| 轴箭头 | 单端 | **双端**——两根轴都有 `marker-start` + `marker-end` |
| 格内容 | 小圆点 + 标签 | **命名情景 + 1–3 行描述** |
| 四角 | 短动作词（优先做） | **编号角标 + 维度组合**（`01 · 维度A / 维度B`） |
| 焦点 accent | 落在一个**条目**上 | 落在一个**格子**上——tint 底 + accent 描边 + accent 角标 |
| 轴线 | 1px `ink` | **1.2px `ink`**（略重——轴承担更多画面） |

两个变体用同一套极简轴标签：每个尖端一个词，无符号、无括号。唯一的轴差别是变体用双端箭头，因此**四个尖端都有标签**。

其余一切——纸底、排版、图例条、4px 网格、复杂度预算——都是默认皮肤。不要为这个变体发明新颜色或新字体。

### 造型 token

- **轴线**：`ink`，`stroke-width: 1.2`，`marker-start` + `marker-end` 双向朝外。
- **焦点象限底衬**：`rgba(125,152,255,0.05)` 整格 rect 垫在最底层。
- **焦点格**：`accent-tint` 底 + `accent` 描边 1.2px；角标 `accent` · 600。
- **非焦点格**：`store` 处理（`ink @ 0.05` 底 + `muted` 描边）。
- **格标题**：sans 16px · 600 · `ink`。
- **格描述**：sans 12px · `muted` · 1–3 行 · 格内左对齐。
- **角标**：格式 `NN · 维度A / 维度B`——两个维度词必须与轴标签**逐字一致**（复制，不要改写）。中文角标 sans 12px · 500 · 0.3em；整条纯拉丁时可用 mono 8px · 0.18em + uppercase。
- **轴标签**：与标准象限同一套极简规则，一个词一个尖端。四个尖端的位置：

  - 上尖端：`text-anchor="middle"`，尖端上方约 12px
  - 下尖端：`text-anchor="middle"`，尖端下方约 20px
  - 左尖端：`text-anchor="end"`，尖端左侧约 12px，`dominant-baseline="middle"`
  - 右尖端：`text-anchor="start"`，尖端右侧约 12px，`dominant-baseline="middle"`

### 布局（变体）

- 四格等大（`240×160` 或 `280×180` 为基准），离轴十字 40–60px。
- 轴十字从**格间**穿过，不穿格。
- 箭头尖端伸出最外格边 20–40px；单词轴标签在尖端外约 12px（见上）。
- **恰好一个焦点格**。不选 = 空模板；选两个 = 信号清零。
- 保留底部图例条 + 发丝线，同标准象限。图例同时给两个样本：「主打赌注」（accent）与「候选情景」（中性）。

### 反模式（变体专属）

- 图表区加底色 / 加纹理——纸面纯白是全技能的承重墙，为「咨询风」加底色，图就沦为通用货
- sans 的页面 H1——标题保持 serif；标题衬线 / 图形无衬线的反差是签名
- 未命名的格（"情景 1/2/3/4"）——空白模板可以，交付物不行
- accent 多于一格——与全技能的焦点规则一致
- 3×3、2×3 网格——那是别的图，不是这个变体
- 格内放定位点——位置有意义就用标准象限
- 轴标签加粗、文字里带箭头符号（`↑ 增长`）、"高/低"前缀——极简轴标签不可谈判
- 角标与轴标签对不上（轴写"远程 / 坐班"，角标写"高远程 / 低 AI"）——读者三秒内会把它当成 bug
