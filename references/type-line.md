# 折线图（Line）

**最适合**：随时间或顺序索引的连续趋势——周注册量、月营收、逐版本延迟。点与点之间的**方向与变化速率**是主要信息时用。

## 布局惯例

- **绘图区边距**：左 80px、下 60px、上 40px、右 40px——`0 0 1000 500` viewBox 内。
- **数据点**：4–12 个。更少 → 考虑一句汇总数字；更多 → 聚合到周期。
- **x 轴**：等距时间 / 索引标签在绘图区下方。纯拉丁（月份缩写、周号）用 mono 9px 居中于每个点的 x；中文用 sans 12px。
- **y 轴标题**：绘图区左侧竖排小标题（`transform="rotate(-90)"`，x≈24，绘图区垂直居中）。中文 sans 12px · 0.3em 字距；纯拉丁走 eyebrow 规格。单位并入标题（如「每周活跃用户（万）」），刻度保持裸数字。
- **y 轴网格线**：4–6 条等距横线，同柱状图的淡处理（`ink @ 0.08`，0.8px）；基线 `ink @ 0.30` 1px。
- **折线**：`<polyline>`，`fill="none"`。焦点系列 `stroke-width="1.8"`，其余 `"1.2"`。
- **顶点圆点**：只给焦点系列（`r=4` 实心）。其余系列只画线。
- **面积填充**：焦点系列在线下默认画一层极淡的强调色面积——`<polygon>` 沿焦点折线闭回 y=420 基线，`fill="accent@0.05"`。绘制顺序：非焦点线 → 焦点面积 → 焦点线 → 顶点圆点。非焦点系列不画面积。
- **多系列**：至多 5 条。焦点 = `accent`；其余按序取 `series-1` … `series-4`（见 style-guide 系列色板），不跳档。
- **图例**：底部横条。**样本跟随系列画法**（业界惯例，同 ECharts / Highcharts / Excel）：折线图样本 = 28×2px 线段（同系列色）；焦点系列只加一样东西——线段中央 `r=4` 圆点，文案用 ink 加粗。一个系列一个样本，焦点不另设样本；图内的粗线 + 圆点 + 面积已把焦点讲清楚。柱状 / 面积类图表的样本才是实心色块（见各类型文档）。
- **页面对齐**：eyebrow 与大标题左缘对齐绘图区左缘（viewBox x=80 → CSS `margin-left: 8%`），不要顶到画布外框。

### 折线范式

```svg
<!-- 焦点面积（先画） -->
<polygon points="x0,y0 x1,y1 x2,y2 ... xn,yn xn,420 x0,420"
         fill="rgba(26,77,217,0.05)"/>

<!-- 焦点系列 -->
<polyline points="x0,y0 x1,y1 x2,y2 ..."
          fill="none" stroke="#1a4dd9" stroke-width="1.8" stroke-linejoin="round"/>
<circle cx="x0" cy="y0" r="4" fill="#1a4dd9"/>

<!-- 非焦点系列 -->
<polyline points="x0,y0 x1,y1 ..."
          fill="none" stroke="#3ba272" stroke-width="1.2" stroke-linejoin="round"/>
```

## 反模式

- 超过 5 条系列（视觉糊——砍掉或拆图）。
- 除非明确标注，折线不从共享零基线起。
- 数据是采样得到的却用平滑曲线——折线才诚实。
- 4 条以上系列还每条都画顶点圆点（只给焦点画）。
- 绝对量级重要时 y 轴不含零。
- 不连续的数据段之间直接连线（要有视觉断口）。
- 顶点 / 线端数值标注——右端空间小，极易与相邻系列线重叠；数值放标题、副题或图例说明里。
