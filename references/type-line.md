# 折线图（Line）

**最适合**：随时间或顺序索引的连续趋势——周注册量、月营收、逐版本延迟。点与点之间的**方向与变化速率**是主要信息时用。

## 布局惯例

- **画布基线**：宽 1000 定死；顶贴 y=0（y 轴线从画布顶起）；高 = 内容底向上取整到 40 的倍数；宽高比为读数非门（见 style-guide「容器对齐与画布基线」）。
- **绘图区**：x 80 → 960（右缘与柱状图网格对齐）、y 20 → 380。数据点 4–12 个、等距分布；**首点骑在 Y 轴上、末点落在网格右端**——线从轴上起排，不在轴外留空。更少点数 → 考虑一句汇总数字；更多 → 聚合到周期。
- **y 轴**：竖排小标题（`transform="rotate(-90)"`，中文 sans 12px · 0.3em，单位并入标题如「每周活跃用户（万）」）；刻度裸数字 mono 9px。
- **网格**：横线 4–6 条 `ink@0.08` · 0.8px；x/y 基线 `ink@0.30` · 1px。
- **折线**：`<polyline>`，`fill="none"`。焦点系列 `accent` 1.8px + 顶点圆点 r=4；其余按序取 `series-1…4` 实色 1.2px，只画线不画点。
- **焦点面积**：焦点系列线下一层 `accent@0.05`，`<polygon>` 沿焦点折线闭回 x 轴基线（y=380）。绘制顺序：非焦点线 → 焦点面积 → 焦点线 → 圆点；非焦点系列不画面积。
- **图例横条**：样本 = 28×2px 线段（焦点样本线段中央加 r=4 圆点）；分隔线距最下内容（轴下刻度标签底）56、右缘贯通 0→1000。
- **页面**：eyebrow「领域 · 折线图」；标题 → 图 3rem；container 四件套（标题不写 margin-left）。

### 折线范式

```svg
<!-- 焦点面积（先画，闭回 x 轴基线 y=380） -->
<polygon points="x0,y0 x1,y1 x2,y2 ... xn,yn xn,380 x0,380"
         fill="rgba(26,77,217,0.05)"/>

<!-- 焦点系列 -->
<polyline points="x0,y0 x1,y1 x2,y2 ..."
          fill="none" stroke="#1a4dd9" stroke-width="1.8" stroke-linejoin="round"/>
<circle cx="x0" cy="y0" r="4" fill="#1a4dd9"/>

<!-- 非焦点系列 -->
<polyline points="x0,y0 x1,y1 ..."
          fill="none" stroke="#3ba272" stroke-width="1.2" stroke-linejoin="round"/>
```

## 深色档

照抄 [`assets/example-line-dark.html`](../assets/example-line-dark.html)：对称换基、α 不动——纸 `#0a0d1b`；网格 `ink` 深基 @0.08、轴线 @0.30；焦点面积 accent 深基 @0.05（α 不动）；系列色取深色档（`series-1` 翠绿 `#5fbf93`、`series-2` 暖橙 `#f2a267`，其余见 style-guide 系列表）；焦点线/圆点 accent 深色档；图例分隔线 `ink` 深基 @0.10。

## 反模式

- 超过 5 条系列（视觉糊——砍掉或拆图）。
- 数据点不贴轴起排（首点悬在轴外，或末点越过网格右端）。
- 除非明确标注，折线不从共享零基线起。
- 数据是采样得到的却用平滑曲线——折线才诚实。
- 4 条以上系列还每条都画顶点圆点（只给焦点画）。
- 绝对量级重要时 y 轴不含零。
- 不连续的数据段之间直接连线（要有视觉断口）。
- 顶点 / 线端数值标注——右端空间小，极易与相邻系列线重叠；数值放标题、副题或图例说明里。

## 变体

### 斜率图（Slopegraph）

**最适合**：**恰好两个**可比较状态间的多条系列变化——两个年份、改造前后、两个人群。一次读三件事，且没有别的类型同时给：方向（升/降）、陡缓（多快）、**交叉**（谁超过了谁）。不适合：三个及以上状态（那是折线图或凹凸图）、单系列（写一句话）、某一时点的排名（用柱状图）、不同单位的两个变量（斜率无意义，用散点图）。

- 两条竖轴即全部刻度，**无网格线**——每个端点直接印数值。
- 左右各留标签槽：名字 + 值两端对齐，槽宽按最长名字定。
- **横距保持小于纵向高**——拉宽横距会把所有斜率压平，丢掉这个类型存在的意义；余宽给标签槽。
- 系列 4–10 条（上限来自端点标签碰撞，不是线条纠缠——斜率图没有中段）。
- 每系列**两端都画圆点**（与母类型不同：这里每系列恰两个顶点，都是读数位置）。
- 颜色：**一个 accent + ink 透明度坡道**，不用系列五色——系列两端都有名字，色相是重复编码；焦点由 accent + 加粗线宽共同承载；文字一律 ink / muted，焦点值不用 accent 写字。
- 诚实数据（本类型的命门）：**两轴同单位、同刻度、同原点**——平移一根轴，排名仍对但每条斜率全错；紧凑值域合法但必须在图注声明；缺端点的系列整条丢弃并说明，**绝不插值**；因标签拥挤而挪动端点 = 数据造假；两端重合的系列合并或弃一条；直线是连接器不是轨迹——不读中间值、不给交叉点注日期。

### 山脊图（Ridgeline）

**最适合**：每系列一个**分布**、固定行距叠放、刻意重叠——形状即故事（各服务延迟分布、各流水线构建时长）。p50/p99 给不出双峰。不适合：单分布（直方图）、不同单位或 x 域的系列、时间序列、形状雷同的五六条（百分位表更短）。

- 每脊一条基线、固定行距；名字在脊左、值域（非零质量跨度）在脊右。
- 3–12 脊、8–40 桶；桶间**直线段连接**、路径闭合——不样条：曲线会在桶与桶之间发明样本没测到的极值。
- 无网格线——基线就是刻度，每脊印自己的值域。

### 凹凸图（Bump）

**最适合**：**3–6 个有序快照**间的名次流动，且位置本身就是故事——包下载量季度排名、团队冲刺战绩、热门榜月度变动。斜率图给两个时刻并保留量级；凹凸图把量级整个交易掉，换**多个时刻的纯位置**：纵轴是名次、每行隔一名，平线读作「没人挤掉它」，不是「没变化」。不适合：恰好两个快照（那是斜率图）、量级故事（量级翻倍而名次不动的那条若重要，读者需要折线图）、少于 4 条系列（一句话更短）。

- 与斜率图同门几何：每快照一条竖轴、轴即刻度、**无网格线**——顶点恰落在排名行上即可读位置。左右标签槽同位（名字 + 名次），名次带 `#` 记号防止被读成量级；只在**首次与末次出现**处标注。
- **排名行固定行距**（示例 y=100+64×名次），顶点必须恰在行上——名次没有小数，为躲标签挤出一格等于谎报了一个不存在的名次。
- 相邻快照间**直线段**、每顶点画圆点——曲线会在快照之间发明没测过的名次轨迹。
- 颜色同斜率图（一个 accent + ink 透明度坡道按首快照名次排序，焦点由线宽与圆点大小承载，文字一律 ink / muted），但**坡道即闭集 {0.60, 0.50, 0.40, 0.30}——非焦点至多 4 条、系列总数至多 5**：第 5 条非焦点会逼出 @0.20 的表外角色，那是虚线与点阵的档位，不是实色数据线。
- accent 标**编辑焦点不标赢家**——落在故事主角上，常常恰是跌落的那条。
- 诚实数据：排名口径与平局判定写进图注（示例「并列沿用上季名次」）——排名掩盖量级是本类型的交易，图注是读者得知「第一」何义的地方；排名量尺在快照间换了定义则整图无效；中途退场或迟到的系列画断口，绝不插值补全。

### 流图（Streamgraph）

**最适合**：总量与构成在多个周期里一起呼吸——按流水线的构建分钟、按服务的流量、按子系统的错误预算。对称基线让**包络成为主角**：流在任一周期的高度即总量，各层在其中保住份额。普通多系列折线丢总量，百分比堆叠面积故意丢总量——两者兼得的只有这一形态。不适合：精确逐期读值（读者得到的是形状——用柱状图或印表格）；两三个周期（母类型折线或斜率图）；单系列（母类型焦点面积已覆盖）；排名故事（凹凸图读名次，流图读体量）。

- 周期列等距 x 80..960（示例 12 周列距 80）；周期 3–24、层 2–5（坡道四档 + 一焦点，第 6 层起色调不可分）。
- **对称基线在绘带垂直中线**（派生线，不画）：每周的堆叠居中其上，包络起伏即总量呼吸；零和基线必须写进口径。底部钉死的「流图」是穿了戏服的堆叠面积。
- **一把线性刻度贯穿所有层所有周期**；刻度或桶宽写进口径。
- 层边界 Catmull-Rom 平滑（控制点 1/6 弦），**顶点在真值上**——平滑只弯周期之间的画线；急变处的轻微过冲是平滑的诚实代价，不许挪顶点去驯服。
- **堆叠序全图固定、最大两层贴中线**，小层骑外侧曲率大的边缘；序绝不逐周期变。
- 层间**纸色 1px 发丝线**分隔（深色档换深底色）。
- 无 y 刻度、无网格——形状即故事；层总量印在图例（数字住在图例里）。
- 至多**一个地标注记**：包络上方短发丝线 + 一行字（示例标焦点层成为最大的一周）；多了形状就不再是主角。
- 颜色：**一个 accent 焦点层 + ink 透明度坡道**，绝不用系列五色——层名图例已给，色相是重复编码。坡道 = ink@`{0.60, 0.45, 0.30, 0.15}` 四档按层总量降序（最重最深，相邻差约一档半；style-guide 枚举特例）；焦点层 accent@0.20（α 梯子「焦点步骤芯片」档，大色域上 hue 挑焦点、不比明暗）。图例措辞皮肤中性（「色调最重」不写「最深」——深色档坡道反向）。
- 诚实数据：**包络是总量的主张、层是份额的主张**——零周期留在域内（夹捏即数据，绝不桥接、重采样或丢弃）；任何层不许悄悄消失（图例层与绘制层一一对应，总量 = 逐周值之和）；桶宽（周 / 日 / 每次发布）写进口径；重采样到粗桶会把故事抹平，读者有权知道自己拿到的是哪个故事。
