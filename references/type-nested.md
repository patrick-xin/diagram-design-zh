# 嵌套图（Nested Containment）

**最适合**：用「包含」表达的层级——作用域边界、配置级联（全局 → 组织 → 项目）、信任域、目录嵌套、爆炸半径。外层 = 更宽泛，内层 = 更具体。

## 布局惯例

- 3–5 个圆角矩形（`rx=8`）嵌套，层间内边距一致（横 24–32px、竖 32–36px 为宜）。
- **最内层保持全宽**：逐层只内缩左右，最内层宽度吃满（只比外层矮，不比外层窄）——它是焦点扁盒，不是居中小方块。内部放大号可读标签（sans 16px 600）+ mono 10px 副标。
- 每层的标签放左上角：中文 sans 12px · 500 · 0.3em（中文角标规格），或纯拉丁时 mono 7–8px · 0.18em。标签下垫 paper 色遮罩矩形，压住该层的上边框。
- **描边梯度**：外层最淡（`ink @ 0.30–0.45`），向内逐层加重到 `muted`、`ink`，最内焦点层 `accent`。
- **填充梯度**：从外到内透明度递增 `ink @ 0.02` → `@ 0.03` → `@ 0.05`，紧邻焦点层的环带回落 `@ 0.03` 让焦点 tint 突出；最内层 `accent-tint @ 0.08` + `accent` 描边 1.4（焦点描边族宽度）。
- 可选文件图标（折角矩形）提示每层的内容物，放各环带右下角、逐层错落。
- 编辑旁注（斜体宋体，见 primitive-annotation.md）至多 2 条：描述放**外部**空白处（画布顶部空带 / 底部余量内，不溢出画布），用 `4,3` 虚线弧线（`Q` 二次曲线 + 端点圆点）引到最内层——标注从外面指进来，不往盒子里塞字。

## 反模式

- 超过 6 层（信息向内湮灭）。
- 最内层画成居中小方块——丢失「包含」的读法，也浪费了焦点位置。
- 层间内边距不规则——错位的嵌套看起来像失误。
- 环里出现不属于该层级的并列内容（改用兄弟图）。
- 多层同时上焦点色（层级信号崩塌）。
- 旁注文字塞进环带内部（描述放外部，虚线引进来）。
