# 瀑布图（Waterfall）

**最适合**：期初总量经带符号的分步变动走到期末总量——预算桥、成本桥、人数增减、转化补偿。运行总量是故事主线时用：每根柱要么锚定总量（期初 / 期末 / 小计），要么桥接前后两个运行水位，读者顺着 carry 线从起点走到终点。

**不是这类型**：

- 独立类目的数量比较 → [type-bar.md](type-bar.md)
- 数量的分流与汇合（会分叉的量） → [type-sankey.md](type-sankey.md)
- 单一收窄量逐级流失 → [type-pyramid.md](type-pyramid.md)

## 布局惯例

- **方向**：竖柱，叙事序左 → 右：期初总量 → 各带符号桥（至多一个小计）→ 期末总量。横排瀑布读起来像甘特图，不画。
- **绘图区 / 网格 / 轴 / 刻度 / 类目标签 / 竖排轴题全部随 bar 家族**（[type-bar.md](type-bar.md)）：绘图区 80..960 顶贴 y=0、网格 6 条 y=20..320 `ink @ 0.08` 0.8px、轴线 `ink @ 0.30` 1px、刻度右对齐 x=48 mono 9px、类目基线 轴+24 sans 12px 600、轴题 `rotate(-90 12 ·)` 12px · 0.3em。
- **柱数 4–8**（含两端总量、至多 1 个小计）；超出并「其他」桥（口径注交代构成）或拆两张。柱宽 72 / 步距 144 / 首柱 x=88。
- **总量锚底，桥浮空**：期初 / 期末（与小计）从轴底画到值；桥恰好跨贡献前后的两个运行水位。
- **符号编码——填充轻重，不靠色相**：增 = `muted @ 0.15` 实心；减 = hollow（纸底填充，深色随纸面换档）；总量 = `ink @ 0.18`（比桥体重的结构档，深色 α 不动）。描边全家族统一 muted 实色 1px。方向由几何（桥的哪端接 carry）与带符号数值双重承载，灰度与色弱下不失真。
- **焦点桥 ≤1**：`accent @ 0.12` 填充 + `accent` 描边，数值同色。
- **carry 线**：柱边到柱边传运累计值，`ink @ 0.50` 1px 实线（「今日线」档——承重线，须明显重于网格）；画在柱下。
- **数值标签** mono 9px 纯数字（单位进口径注）：总量与增印柱顶上方（top−8）、减印柱底下方（bottom+12——减的上方是 carry 到达位）；桥带显式符号 `+` / `-`，总量不带。
- **图例**：四样本复刻柱处理（期初 / 期末总量 · 成本增加 · 成本减少 · 焦点）；口径注右锚 x=1000。
- **画布高** = ceil40(图例基线 + 10)，与 bar 家族同式。

## 诚实规矩（走账必须平）

- **运行总量守恒**：期初 + 全部带符号桥 = 每个小计 = 期末，精确相等——账不平的瀑布不是大约对，是错。
- **桥恰好跨它的两个运行水位**（共享比例尺）。数据可选时取 4 的倍数、k 取 1，像素即数值；真实数据不可选时坐标取整到整像素即可（数据坐标不承担 4 网格，柱 x / 宽是布局、仍上网格）。
- **carry 画在它传运的水位上、跨满缺口**——画错高度等于把账接到另一个总数上。
- **每柱印值、桥带符号**；零桥不画（口径注交代，不画隐形墨水）。
- **值域自 0 起**（总量锚在轴底）；全距远离 0 的两端对比是别的类型的活，硬画等于每条桥被放大。

## 反模式

- **浮桥无 carry 线**——carry 是「总量跨缺口守恒」的声明，没它就是几根悬空柱。
- **符号用色相**（绿涨红跌、accent 满图）——填充轻重 + 几何 + 符号才是编码，色只留给焦点桥。
- **截断值轴**（不从 0 起）。
- **多于 1 个小计**——需要多个歇脚点的走账是两段走账，拆两张。
- 中途换单位；3D、阴影、圆角桥柱；类目名旋转（过长就缩写，不转）。
