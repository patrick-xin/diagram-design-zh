# 极坐标图

**最适合**：**一个**定量序列落在 4–8 个类目上，且类目的**顺时针次序本身有意义**（时辰、星期、月份——绕一圈回得到起点的类目）。多个实体打分对比用 [雷达图](type-radar.md)；类目绕圈没意义就用 [柱状图](type-bar.md)；超过 8 个有序时段用 [折线图](type-line.md)。

## 输入契约

一个序列、一套共享线性刻度：`min = 0`、`max > 0` 有限值；每个值满足 `0 ≤ v ≤ max`；类目标签去空白后唯一、数量 4–8；焦点类目 ≤1；**类目保持输入次序**——按值排序会毁掉环形含义。缺值不归零：停下来问用户是删类目还是补值，不许把缺值画成 0。

## 量化编码

类目 `i`（共 `N` 个）、值 `v`、圆心 `(cx, cy)`、外半径 `R`：

```
theta_i = start_angle + clockwise_sign × 2π × i / N     （start_angle 默认 -90°=12 点方向）
radius_i = R × v / max
x_i = cx + radius_i × cos(theta_i)
y_i = cy + radius_i × sin(theta_i)
```

**半径是唯一编码**：射线是从圆心到 `(x_i, y_i)` 的线段，可见长度与 `v` 严格成正比；端点圆恒定半径（r=4，焦点 5），不承载额外量；**任何射线下面都不许放填充扇形**——面积会跟声明的半径编码抢话。`v = 0` 时不画射线也不画端点，只留 faint 辐线并把数值标签写成 0；圆心一枚 0 刻度即共享零基线，**不许**加最小 hub、最短射线或位移端点。

## 布局惯例

- 五条网格环 = 20% / 40% / 60% / 80% / 100% 刻度（`rule @ 0.08`，外环=满刻度边界提 `@ 0.20`）；类目辐线中心到外环同 `@ 0.20`。环与辐线是结构网格，**永远不染类目色**。
- 刻度数字只标首轴一枚（20..100，mono 9px），圆心一枚 0。
- 非焦点射线 `muted` 2px；焦点射线 `accent` 2.4px。端点标记：纸色填充 + 射线同色 1.2px 描边——棒棒糖头，不是气泡。
- 类目标签在 `R + 28`（sans 12px · 600），**水平不旋转**——切向旋转降低可扫读性，属于被否掉的定性转盘方向。数值标签在 `R + 44`（mono 9px），单位写在口径注里不重复八遍。
- 标签锚点：±15° 内的近竖直类目 `middle`；右半 `start`、左半 `end`；正水平类目的数值标签 `dy=16` 挪到类目名下方。
- 绘制顺序：环 → 辐线 → 刻度 → 非焦点射线 → 焦点射线 → 端点 → 类目标签 → 数值标签 → 口径线。
- 单序列无图例条：底部一条口径线（贯通 0→1000）+ 口径注（含单位与数据口径）。
- 灰度可读：位置与数值标签承载数据，accent 只负责指路。

## 几何

三档同构 `viewBox 0 0 1000 520`，圆心 `(500, 230)`，`R = 160`：环 r = 32/64/96/128/160；首轴刻度自环心向 12 点；类目/数值标签见上。full 版套讲解框不改图内几何。

## 复杂度预算

| 上限 | 规则 |
|---|---|
| 类目 | 8（下限 4） |
| 序列 | 恰好 1 |
| 焦点类目 | 1 |
| 编码 | 半径唯一；五环一刻度轴 |
| 产出 | 静态——要交互或多一种编码就拆图或换类型 |

## 反模式

- **环形 hub 或任何非零内基线**——圆心就是 0。
- **填充扇区 / 楔形 / 渐变带**——面积不编码任何量。
- **切向或旋转的类目标签**——水平是可扫读的底线。
- **一张极坐标叠多个序列**——那是雷达图的事。
- **截断径向刻度**（min ≠ 0）——半径比例直接失真。
- **按值排序类目**——环形次序是数据的一部分。
- **缺值画成 0**——0 是测量出来的，不是填出来的。
- **性格轮盘 / 能力盘 / 角色画像这类定性扇区**——扇区是定性的就不是本类型；用选一张诚实的非极坐标表达。
