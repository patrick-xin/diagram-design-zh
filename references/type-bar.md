# 柱状图（Bar / Column）

**最适合**：跨类目或时间段的离散数量比较——迭代吞吐、月度营收、功能采用率、批次计数。每个类目只有一个数值、且「柱与柱的高低差」就是主要信息时用。

## 布局惯例

- **方向**：竖柱为默认。类目名很长或类目超过 8 个时改用横柱。
- **绘图区边距**：左 80px（y 轴标签）、下 60px（x 轴标签）、上 40px、右 40px——`0 0 1000 500` viewBox 内。
- **柱数**：4–8 根。超过 8 根 → 按周期分组或拆两张图。
- **柱宽**：≥ 柱距的 50%（空隙不许宽过柱体）。常用：间距 110px、柱宽 72px。
- **y 轴网格线**：4–6 条等距横线。描边 `ink @ 0.08`（极淡），0.8px；x 轴基线 `ink @ 0.30`，1px。
- **y 轴标签**：右对齐 mono 9px `muted`，x=72（绘图区左缘再让 8px）。纯数字用拉丁行。
- **x 轴标签**：每根柱下方居中，中文类目名 sans 12px 600。
- **数值标签**：柱顶上方 mono 9px。焦点柱的数值用 `accent`，其余 `muted`。
- **焦点柱**：至多 1 根——`accent-tint` 填充 + `accent` 描边，数值同色。其余柱 `muted @ 0.15` 填充 + `muted` 描边。
- **y 轴线**：x=80 处细竖线，y 从 40 到 420。

### 柱元素范式

```svg
<!-- 柱体（浅色档） -->
<rect x="X" y="Y" width="W" height="H"
      fill="rgba(86,94,126,0.15)" stroke="#565e7e" stroke-width="1"/>
<!-- 柱顶数值 -->
<text x="X+W/2" y="Y-8" fill="#565e7e" font-size="9"
      font-family="'Sarasa Mono SC', ui-monospace, monospace" text-anchor="middle">VALUE</text>
```

焦点柱：填充换 `accent@0.12`，描边与数值换 `accent`。

## 反模式

- 超过 8 根柱不分组（常规尺寸下不可读）。
- **截断 y 轴**（不从 0 起）——数量对比被扭曲。
- 焦点色落在多于 1 根柱上（「都重要」= 都不重要）。
- 3D 柱体、阴影、深度效果。
- 类目标签旋转超过 45°；标签太长就换横柱图。

## 变体

- **分组柱**：每类目两根并排。主系列用 `accent`，次系列用 `series-1`。至多 2 组。
- **堆叠柱**：分段叠到总量。焦点段用 `accent`，其余段用 muted 系淡染；每叠顶部标总量。
