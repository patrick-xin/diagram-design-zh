# 用户旅程 / 体验地图

**最适合**：一个人在一个体验的各阶段**做什么**、又**感觉如何**。情绪曲线是承重元素——说不出每个阶段一种感受，就只是多了几行的流程图，改用 [流程](type-process.md) 或 [时间线](type-timeline.md)。反过来，没有人的内部系统流（无角色、无感受）是架构图或数据流的事。一张图只放**一个**用户画像；两个画像的情绪曲线叠在一张图上会互相抹掉。

## 布局惯例

纵向堆叠，自上而下四层：

- **列头**。等宽阶段列（默认五列），每列两行：角标「阶段 N」（中文角标档：sans 12px · 500 · 0.3em）在上，阶段名（14px · 600）在下，都居中于列心。
- **情绪带（本类型的存在理由）**。列头正下方 160 高的绘图区，三条档位发丝线（`rule @ 0.10`）标 **高 / 中 / 低**——只标实际用到的档；档位标签在左缘**横排**（`text-anchor="end"`），永不竖排。一条 `muted` 1.8px 折线（家族数据线档）穿过每列一个 r=4 圆点，取值只落在**五档序数**上：高 / 中高 / 中 / 中低 / 低——是命名档位，不是 0–100 打分。
- **数据线豁免**。情绪曲线是数据线不是连接线——SKILL §8 规则 1（强制圆角肘）不适用于它。豁免只覆盖曲线本身；旅程图里通常没有其他连线，若有，照走 §8。
- **内容行**。情绪带下方 ≤3 行带区，行标签在左缘横排（与档位标签同列）：**行为**（用户做什么，ink 12px，每阶段一行短句）、**触点**（发生在哪个面上——注册页、应用内弹窗、企业微信——muted 12px）、可选第三行放度量或责任方。行间发丝线**贯通整个绘图区**（从左边距到末列右缘）。
- **痛点芯片**。只挂**谷底阶段**的行为行下：`rx=2` 小盒（160×16），`accent-tint` 填充 + `accent @ 0.50` 虚线 `4,3` 描边，芯片内中文 10px `accent` 实色。芯片够宽装得下 10px 中文就走中文（判别标准是装不装得下，不是芯片身份）；写**摩擦**（用量 80% 无提醒），不写修复方案。
- **焦点规则**。恰好 2 个 accent：谷底入线段 + 谷底点（合算一处），痛点芯片（合算另一处）。其余一切曲线、点、文字一律 `muted` / `ink`。
- **图例**。三项按序：情绪曲线（线样 + 点样）、低谷段（accent 线样 + 点样）、痛点标记（缩样）。痛点盒 160 实宽进图例会撑爆横条——样块用 16×12 缩样，描边与虚线同档；「复刻芯片实际尺寸」只适用于芯片级小样。

## 几何

按 `0 0 1000 480` 标准画布。左边距 64（挂档位与行标签，`text-anchor="end"` 至 x=56），五列 168 宽、沟 24：

```
col_center(i) = 64 + 84 + 192 × i    →  148 / 340 / 532 / 724 / 916
```

- 列头：角标基线 y=20、阶段名基线 y=40（内容四贴·顶贴带）。
- 情绪带：三档发丝线 y = 80 / 160 / 240（间距 80）；五档内插档（中高 / 中低）在档间中点 120 / 200。圆点 x=列心、y=所在档线。
- 行带：情绪带底分隔线 y=260；行为行 260–356（文字基线 280，痛点芯片 292 起、两枚叠放隔 4）；触点行 356–392（基线 392）。
- 图例：分隔线 = 触点行底 392 + 56 = 448，基线 466；画布高 = 内容底（图例色块底 468）取整 40 倍数 = **480**。

**六阶段收窄**：1000 − 64 = 936，六列则列宽 (936 − 5×24) / 6 = 132——低于痛点芯片宽 160。要画第六阶段必须同步收芯片（文字压到 10px 下限附近），默认答案是拆两张旅程（如获客与留存），不硬塞。

## 复杂度预算

| 上限 | 规则 |
|---|---|
| 阶段 | 6（默认画布 5；第 6 列见几何节） |
| 内容行 | 3 |
| 情绪档位 | 五档序数（命名档，非数值） |
| 痛点芯片 | 2，且只挂谷底阶段 |
| accent 元素 | 2（谷底段+点、痛点芯片） |

## 反模式

- **没有情绪曲线。** 每个阶段感受相同、或说不出感受——那是流程图，用流程或时间线。
- **数值情绪轴（0–100 分）。** 情绪是五档序数不是连续指标；画成分值图就成了一张没人信的柱状图。
- **emoji 当情绪标记。** emoji 不本地化、印刷糊、小尺寸垮——用命名档位与发丝线。
- **一张图两个画像。** 两条曲线叠着，谁也读不出——一图一画像。
- **每个阶段都挂痛点。** 没有未标记的阶段就没有焦点——痛点只挂谷底。
- **竖排行标签。** 横排、左缘——与全技能规矩一致。
- **拿它画无人的内部系统流。** 没有人、没有感受、没有旅程——那是架构或数据流。
- **痛点芯片写解决方案。** 「加一条 80% 告警」是修复；芯片写摩擦本身，修复属于正文。
- **超过 6 个阶段。** 拆两张旅程，别把宽漏斗硬塞进一张图。
