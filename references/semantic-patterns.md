# 语义模式

语义模式描述系统**做什么**；视觉类型描述信息**怎么排**。当行为、状态、执行、风险承载含义时，先选语义模式，再用它最近的视觉类型当布局语法。没有匹配的模式就直接选视觉类型。

每张图只用一个主模式。第二个模式至多贡献一个辅助基元；两个都要完整表达就拆成总览 + 细节两张图。静态画面里标签与结果必须完整。

**类型映射说明**：下表「最近类型」按本技能内置的 28 类给出（完整清单见 SKILL.md §3 路由表）。模式与类型正交：模式提供语义基元与更紧的预算，类型提供布局语法。

## 路由表

| 读者要理解… | 语义模式 | 最近视觉类型 |
|---|---|---|
| 多路来量争抢有限的服务能力 | **汇聚排队 / 瓶颈** | 数据流 |
| 同一组问题/输入/管控/输出在各阶段重复出现 | **带语义槽位的阶段框架** | 泳道（阶段做轴）；生命周期叙事用时间线 |
| 松散对话沉淀为结构化记录 | **非结构化输入 → 结构化产物** | 数据流 |
| 两次策略判定为何不同、在哪一步分叉 | **成对策略评估追踪** | 流程图；消息时序也载荷重时用时序图 |
| 哪些路线跨过信任边界、哪些被挡住 | **安全铺路** | 架构图 |
| 每个执行面上分别落了哪些管控 | **治理 / 管控清单** | layers（执行面成带） |
| 纵深防御如何逐层削减风险、剩多少 | **补偿式安全分层** | layers（威胁自上而下） |

## 1. 汇聚排队 / 瓶颈

**何时选**：多个生产方汇聚到同一个评审人、服务、网关或受限资源上；故事取决于到达率、队列深度、等待、容量或背压。

**必备基元**：各自独立来源；扇形入口；带可见槽位与计数的有序队列；容量/服务速率标签；唯一受限服务点；接纳与延迟/拒绝两条出路。标签带单位（`8/小时`、`3 槽位`），不许只写"高"。

**复杂度预算**：≤5 来源、≤5 队列槽、1 瓶颈、2 结果、主节点 ≤9。多余来源聚合成一个命名群体。

**反模式**：等宽流水线掩盖争抢；箭头过早合并到无法追溯；容量只用盒子大小暗示；装饰性的堆积；动效改变条目顺序；只用红色表示过载。

**静态回退**：展示代表性的最终队列、数字计数/容量、瓶颈标签、两条出路。静止画面必须能看出"工作为什么在等"。

**最近类型**：数据流（来源分区 → 队列 → 服务点 → 出路，正交肘线）；服务阶段（而非来源）主导时考虑泳道。动效示例：[`assets/example-queue-animated.html`](../assets/example-queue-animated.html)。

## 2. 带语义槽位的阶段框架

**何时选**：一个生命周期或运营模型在多个阶段重复同一组语义问题（常见为：问题、输入、管控、输出）。跨阶段可比性比消息时序更重要。

**必备基元**：有序阶段头；一致的槽位网格；显式的空槽/不适用槽；阶段间接力；稳定的槽位标签；每阶段一个主产出。每个阶段内槽位顺序一致。

**复杂度预算**：3–6 阶段、3–4 种槽位、≤20 个有内容格子、每格 ≤2 行。某格需要成段文字就拆细节图。

**反模式**：每个阶段自造一套内部布局；槽位含义只靠位置不给标签；几十个格子堆假精度；把阶段顺序和职责泳道混为一谈；为塞下一块画布缩小文字。

**静态回退**：完整渲染阶段 × 槽位矩阵，接力与显式 `—`（不适用）条目都在。不许依赖分步揭示来教读者看懂框架。

**最近类型**：泳道（阶段为相位轴、槽位为行）；仅当重复的行代表负责人而非语义槽位时更该用泳道；纯生命周期叙事可用时间线。

## 3. 非结构化输入 → 结构化产物

**何时选**：对话、笔记、提示词或一段啰嗦的需求被引导、归一化，写进持久的简报、工单、记录、schema 等结构化产物。

**必备基元**：源语句；澄清式提问；抽取出的字段/值对；命名的转换步骤；产物边界；从代表性语句到字段的溯源连线；缺失/未知状态。

**复杂度预算**：≤4 轮对话、≤6 个产物字段、1 次转换、≤3 条溯源线。展示代表性内容，不贴完整转录。

**反模式**：两个盒子中间放"AI 魔法"星光；产物画成又一个聊天气泡；字段凭空出现没有来源；给缺失的事实编造确定性；打字动画成了唯一可读的文案。

**静态回退**：一段源摘录旁放着已填好的带标签产物，至少一条溯源映射可见，未知字段可见。

**最近类型**：数据流；引导过程有多个有序关卡时考虑泳道。

## 4. 成对策略评估追踪

**何时选**：两个原本相似的请求走到不同结果；读者需要逐规则的 `通过 / 失败 / 跳过 / 未到达` 状态和首个分歧点。

**必备基元**：两条追踪用同一套有序规则；状态用文字 + 符号/形状双通道；不同的输入项；最终结果；带标签的首个分歧标记；区分**跳过**（该流程被有意绕过）与**未到达**（评估更早停止）。

**复杂度预算**：恰好 2 条追踪、3–6 条规则、1 个首分歧、≤12 个状态格、每条追踪 1 个结果。规则文字超一行就移到注释。

**反模式**：两条各自排序的流程硬凑对比；只有红绿点没有文字；把"跳过"和"未到达"当同义词；高亮每一个差异；被拒的追踪继续跑下游规则。

**静态回退**：一次展示全部规则状态与两个结果；首个分歧用常驻的括线/标记 + 标签。

**最近类型**：流程图（有序判定逻辑）；只有当参与者之间的消息和时间也载荷重时才用时序图。动效示例：[`assets/example-policy-trace-animated.html`](../assets/example-policy-trace-animated.html)。

## 5. 安全铺路

**何时选**：一套受支持的架构形成从接入/构建到部署的有界路线；信任边界、特权时刻、许可入口、禁止入口、批准与被挡的部署路径本身就是主题。

**必备基元**：带标签的信任边界；参与者与身份；许可入口配正面文字标签；禁止入口终止在边界上；批准的部署路径；被挡的旁路；特权关卡；隔离运行时；审计去向。线型与停止符号要在颜色之外独立可辨。

**复杂度预算**：≤3 信任区、≤8 组件、≤10 条路径、≤2 条禁止路径、1 个特权关卡。管控细节拆成清单图。

**反模式**：虚线框写个"安全"却没有任何路线语义；禁止箭头穿过保护区的边界；秘密或身份暗示了却没标；所有组件都画成受信样式；旁路视觉上又汇回批准路线。

**静态回退**：全部边界与许可/禁止路线都渲染。被挡路径必须 visibly 停在入口或部署之前。

**最近类型**：架构图。动效示例：[`assets/example-paved-road-animated.html`](../assets/example-paved-road-animated.html)。

## 6. 治理 / 管控清单

**何时选**：一组管控 inventory 要按"在哪执行"来理解：创作、工作区、合并/CI、部署/运行时或其他命名面。一张平铺清单会藏掉这些执行点。

**必备基元**：按执行面分组；命名的管控项；执行者（`代码` / `平台` / `人`）；时机（`编写` / `合并` / `部署` / `运行`）；可绕过性或例外路径；覆盖/缺口标注。

**复杂度预算**：3–5 个执行面、每面 3–7 项、总计 ≤24 项、每项 ≤3 个属性。只有当明细另有清单时才汇总计数。

**反模式**：35 颗小药丸；按模糊主题而非执行点分组；把愿景和已执行的管控混在一起；只有图标没有管控名；没展示面覆盖就宣称纵深防御。

**静态回退**：完整分组清单 + 面头 + 执行者与时机的文字标签；缺口与例外保留。

**最近类型**：layers（执行面自上而下成带）；角色权限而非执行面占主导时，用矩阵思路（参照 quadrant 的网格纪律）。

## 7. 补偿式安全分层

**何时选**：没有一层是完美的；每层防御覆盖上一层漏掉的失败，残余风险要在栈里可见地收窄、转移或存续。

**必备基元**：有序的威胁/风险输入；命名的防御层；每层的缓解措施；显式的局限或逃逸；层间传递的残余风险载体；最终残余风险与后果/响应。用标签或递减度量，绝不只用面积。

**复杂度预算**：3–5 层、1 条主风险线、每层 ≤2 项缓解、1 句最终残余风险陈述。多条不相关的威胁拆成多张图。

**反模式**：暗示最后一层之后风险归零；等大的不透明板砖之间没有传递；把审计当预防；形状缩小却没有数字或文字含义；预防/检测/恢复的顺序倒挂且不解释。

**静态回退**：完整传播链：初始风险 → 缓解 → 每层的逃逸风险 → 最终残余风险与响应。

**最近类型**：layers；当含义在包含边界而非有序补偿时，改用嵌套图（[type-nested.md](type-nested.md)）。

## 组合规则

- 语义模式可以特化状态、边界、队列、传播类基元；选定的视觉类型仍然拥有页面轴向、连线语法、间距与类型级限额。
- 模式预算与类型预算取更严者。语义格子/状态不是突破九节点总览目标的许可。
- 状态与结果用稳定文字。颜色、动效、位置只强化含义，绝不单独承载含义。
- 可选动效是呈现层，不是又一种模式。只在用户点名动效或动效确实讲清有序变化时载入 [`animation.md`](animation.md)。
