# 思维导图（Mindmap）

**最适合**：发散整理——头脑风暴、知识框架、运营方案的分支展开。结构是**层级 + 归属**（什么属于什么），没有量级、没有顺序、没有依赖；把一个主题拆成几支、每支再拆组，一眼看全拆解的骨架时用。

**不适合**：严格分类树（用[树形图](type-tree.md)——分类树要的是整棵树的并列与尾部归并）；依赖关系（用[依赖图](type-dependency.md)）；有先后顺序的（用流程图）；带数量比较的（那是图表的事，往叶子上标百分比是类型误用）。

## 布局惯例

- **根胶囊锚左**：ink 实色圆角胶囊（160×56 · rx=28）贴 x=0、放垂直居中带，主题词反白 14px/600——整张图唯一的非系列色块就是视觉锚。
- **向右放射**：支路从根右侧贝塞尔 S 曲展开，三级封顶（根 → 支 → 组 → 叶）；更深就拆图，四级的导图在常规尺寸下不可读。
- **线宽即层级**：连线 `stroke-width` 随深度递减——2 → 1.4 → 1。层级读数交给线宽，不靠颜色深浅。
- **色只编码归属**：分支色 = 分类编码（图例职能，与系列色板同源——style-guide「不许回填非图表类型」的合法例外，同 data-flow 载荷芯片先例）。**一级支名用支色**（12px/600），二三级文字回 ink；超过五支时并支（系列色板只有五档）。
- **支间不交叉**：相邻支扇形展开，交叉的支路说明分组该重排。
- 画布：宽 1000 定死、高 = 内容底取整 40 倍数（示例 1000×680）；内容不越出画布。

### 元素范式

```svg
<!-- 根胶囊 -->

<text x="80" y="333" fill="#ffffff" font-size="14" font-weight="600" ...>账号运营</text>
<!-- 一级支连线（S 曲，线宽 2）+ 支名（支色） -->
<path d="M 160,328 C 214,328 214,72 268,72" fill="none" stroke="#3ba272" stroke-width="2"/>
<text x="280" y="76" fill="#3ba272" font-size="12" font-weight="600" ...>内容策划</text>
<!-- 二级组（1.4）与三级叶（1.0）：文字回 ink -->
```

## 深色档

照抄 [`assets/example-mindmap-dark.html`](../assets/example-mindmap-dark.html)：对称换基——纸 `#0a0d1b`、ink 文字与胶囊换深色基（`#e0e4ff`）、胶囊反白字换深底；分支色取系列色板深色档（翠绿 `#5fbf93` 等，色相恒定）；线宽与几何不动。

## 反模式

- 四级以上深度（拆图，别硬塞）。
- 叶子标数量 / 百分比 / 日期——导图不携带量级，要比较就去图表。
- 分支色超出系列五色、或一支多色。
- 放射布满全画布外圈（越界即红）；对称扇形失衡（一侧挤一侧空）是分组问题，不是间距问题。
- 给连线加箭头——归属没有方向。
