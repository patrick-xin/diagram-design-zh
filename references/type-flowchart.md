# 流程图（Flowchart）

**最适合**：决策逻辑、算法、面向用户的分支流程（"要不要…？"）、新人引导路由、客服分流、审批流。

## 形状语法（形状承载类型，不靠颜色）

| 形状 | 画法 | 含义 |
|---|---|---|
| 起止 | 胶囊矩形（`rx=20`） | 开始 / 结束端点 |
| 步骤 | 矩形 `rx=6` | 动作 / 处理 |
| 判断 | 菱形 | 决策，出口 ≤3 |
| 汇合 | 实心墨点 `r=4` | 分支重新汇合处 |

- 流向默认上→下。
- 菱形出口惯例：**是**向下（主干）、**否**向右（分支）；但惯例不能替代标签——**每条出线必须带标签**。
- accent 用在快乐路径的终点或最关键的一个判断上，绝不全图焦点色。
- **全图实线，流程图不用虚线**——虚线语义（复核 / 退回）留给泳道图；流程图的打回就是一个普通的实线分支。
- 两线交越：次要线加 8px 半圆跳线（SKILL.md §8.6）。
- 菱形文字 ≤6 个汉字（菱形只有中部够宽）；放不下就拆成两个判断。
- 是 / 否 / 通过 / 打回这类分支标签：sans 10–12px · 500 + `paper` 遮罩（同 SKILL.md §8.3）。标签**骑在线上**：mask 断口中心对准线段中点（水平线 y 居中、竖直线 x 居中），不是悬在线旁。遮罩沿线的方向留 ~4px 净空——竖线上的标签 mask 取 18px 高，别让切断的线头贴字、也别把线下段吃没。

## 布局

- 主干居中一列，分支向右展开，终点胶囊右侧对齐一列。
- 步骤名 12px sans 600；子标签：技术串 / 短语 mono 10px。
- 节点 ≤9。**判断菱形宽高比 ≈ 2:1（如 200×96）**——太扁的菱形（3:1 以上）文字会溢出尖角区，看着也不稳。

## 反模式

- 用填充色区分节点类型——形状已经承担了这个信息
- 菱形画成 3:1 的扁片——宽高比回到 2:1
- 虚线分支——流程图全实线，虚线是泳道图的词汇
- 菱形 4 个以上出口——拆成嵌套判断
- 没有标签的分支
- 菱形里塞长句
- 中文标签 <10px
