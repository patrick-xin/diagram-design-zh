# 手绘滤镜（sketchy 变体）

可选位移滤镜，让所有描边和边缘轻微抖动——把任何极简变体变成手绘"随笔"质感，布局不变。用于图表伴随文章叙事出现的场合，而非技术文档。

## 语法

```svg
<defs>
  <filter id="sketchy" x="-2%" y="-2%" width="104%" height="104%">
    <feTurbulence type="fractalNoise" baseFrequency="0.02" numOctaves="2" seed="4"/>
    <feDisplacementMap in="SourceGraphic" scale="1.5"/>
  </filter>
</defs>

<!-- 滤镜挂在包裹形状的组上——不挂文字 -->
<g filter="url(#sketchy)">
  <!-- rect / path / circle / line 放这里 -->
</g>

<!-- 文字放在滤镜组之外的兄弟组——保持清晰 -->
<text ...>标签放这里</text>
```

## 调参

| 参数 | 范围 | 效果 |
|---|---|---|
| `baseFrequency` | 0.01–0.04 | 低 = 懒散波浪线；高 = 紧张抖动。默认 0.02。 |
| `numOctaves` | 1–3 | 大 = 噪声细节多。2 足够。 |
| `scale` | 1–6 | 1 若隐若现，默认 1.5，2 明显，4+ 卡通。 |
| `seed` | 整数 | 换一个就是另一套随机纹理。 |

## 关键规则

**只滤形状，不滤文字。** 位移映射后的文字不可读——中文笔画密度比拉丁文高，糊得更快。SVG 结构必须让文字位于滤镜组之外的兄弟组。

## 何时用

- 随笔 / 博客 / newsletter，图是叙事页面的主角。
- "草稿感"语域——表达某事还在推敲中，不是最终定稿架构。

## 何时不用的场合

- 技术文档（精确性优先）。
- 标签密集或对齐紧凑的图（滤镜读起来像噪声）。
- 深色变体——抖动在深色底上像渲染瑕疵，要先测试。
- 小字号中文文本周边——12px 以下汉字笔画被位移后最先糊。
