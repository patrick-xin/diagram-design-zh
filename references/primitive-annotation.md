# 标注旁注（斜体宋体 aside）

编辑性旁注的语法——一条"斜体指针"标记细节，但不与图表主体语法竞争。想象书页边批：*"结构即索引"*、*"无需导入，无需配置"*。

## 语法

```svg
<!-- 1. 斜体宋体文本（serif 栈） -->
<text x="904" y="36" fill="#29314f" font-size="14" font-style="italic"
      font-family="'Noto Serif SC', 'Songti SC', 'SimSun', serif" text-anchor="end">无需导入，无需配置</text>
<!-- 2. 虚线贝塞尔引线 -->
<path d="M 820 44 Q 700 84 520 216" fill="none"
      stroke="rgba(41,49,79,0.40)" stroke-width="1" stroke-dasharray="4,3"/>
<!-- 3. 落点圆点 -->
<circle cx="520" cy="216" r="2" fill="#29314f"/>
```

## 规则

- **斜体 + 宋体**共同标示"编辑旁白"的声音，与图内的 sans 正文 / mono 技术标签形成对比。不许换成斜体 sans 或斜体 mono——这个组合是承重的。（中文宋体没有真斜体，浏览器合成倾斜即可，视觉语义不变。）
- 虚线引线（`stroke-dasharray="4,3"`）区分旁注引线与主箭头（主箭头是实线）。
- 旁注放页边（右上、左下），绝不进入图的活跃区域。
- 每图最多 **2 条**。再多就成了评论，不是信号。

## 颜色（语义角色）

| 意图 | 文本 | 引线 |
|---|---|---|
| 中性旁注 | `ink` | `ink@0.40` |
| 焦点旁注 | `accent` | `accent-dark@0.50` |
| 三级（弱化） | `muted` | `ink@0.30` |

深色变体：ink 基的 rgba 按反转规则翻转为纸色基，文本用深色档 ink（见 [style-guide.md](style-guide.md)）。

## 反模式

- 实线箭头引线——会被读成流向箭头。
- 斜体 sans / 斜体 mono——宋体是承重的。
- 引线穿过主箭头 / 生命线——挪到干净的页边。
- 用旁注去标图本身该直接标注的东西——那种标签放元素上。
