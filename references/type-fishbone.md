# 鱼骨图 / 石川图（根因分析）

**最适合**：结构化根因分析。一个观测到的效果，原因按类别分组，每根类别骨下再挂子因。它是事故复盘的标准产物——当读者需要看到**调查过什么**、而不只是结论时用它。反过来，一串按时间先后发生的失败是时间线或时序图的事；鱼骨只回答一个问题：这个「果」是由哪些「因」撑起来的。

## 布局惯例

- **主骨**。水平线（`ink` 实色 1.2px）位于纵向中心 `CY`，尾端**贴画布左缘 x=0**（与标题左缘同线），右端以箭头收进**效果盒**——效果盒走节点盒模式（SKILL §6），盒内写观测到的效果陈述。
- **类别骨**。与主骨固定成 **60°** 的斜直线，沿主骨等距、上下交替。每根骨的外端带类别名，装在小角标盒里（`rx=4`，不许药丸形）——中文 sans 12px · 600。
- **子因**。短水平刻线（32px，`muted` 实色 1px）挂在骨的固定分数处，**右端落在骨线上**（挂接，不穿骨）；标签在刻线开口端外侧，并**与刻线垂直居中**——基线上下同一偏移，上排骨与下排骨完全镜像，不设差异档。中文 sans 12px · `muted`。
- **斜线豁免**。SKILL §6 规则 1（强制圆角直角肘）不适用于 60° 类别骨——斜骨就是本类型的定义语法。豁免只覆盖**类别骨与子因刻线**；图里任何其他连线（标注引线、交叉引用箭头）仍走圆角直角肘。
- **焦点规则**。恰好一根骨是已实锤的根因：骨线 `accent` 实色，它的类别角标用 `accent-tint` 填充 + `accent` 描边。效果盒同款处理——它是全图的标题。这一对（根因骨+角标、效果盒）就是 2 个 accent 预算的全部；其余骨、角标、刻线一律 `ink` / `muted`。
- **绘制顺序**：背景 → 主骨 → 类别骨 → 子因刻线 → 子因标签 → 类别角标 → 效果盒 → 图例。先线后盒——盒体填充把线的端头盖干净。

## 几何

按 `0 0 1000 480` 标准画布。主骨 `CY = 196`（顶排角标盒顶 y=16，内容四贴·顶贴带）；效果盒左缘 `HEAD = 820`（盒 140×96，x 820..960，居中于 `CY`）；骨距 `s = 104`。骨 k（1 起始，k=1..5）在主骨上的挂点：

```
attach_x(k) = HEAD - s × (k + 1)      →  612 / 508 / 404 / 300 / 196
```

骨上下交替（k 奇数在上、偶数在下）。骨的外端——类别角标盒的中心——是 60° 取整偏移：

```
dx = -84
dy = ∓144            （减 = 上，加 = 下；84:144 ≈ tan 60°）
far_x(k) = attach_x(k) - 84
far_y(k) = CY ∓ 144
```

dx 与 dy 都被 6 整除——子因挂点因此全部落在整数坐标上。

### 五骨预计算表（HEAD=820，CY=196）

| 骨 k | 侧 | attach (x, y) | 外端 far (x, y) |
|---|---|---|---|
| 1 | 上 | 612, 196 | 528, 52 |
| 2 | 下 | 508, 196 | 424, 340 |
| 3 | 上 | 404, 196 | 320, 52 |
| 4 | 下 | 300, 196 | 216, 340 |
| 5 | 上 | 196, 196 | 112, 52 |

**第 6 根骨会裁切**：k=6（下侧）挂点 x=92、外端 x=8——角标中心压在画布左缘上。**5 是默认画布的天花板**。要画第 6 根，骨距与 `HEAD` 必须**一起**收窄（只收骨距会把子因标签挤到相邻骨上，只动 HEAD 会把效果盒顶出右缘——我们的 HEAD 没有向右的余量，效果盒右缘 960 已贴着画布右缘的呼吸带）；更常见的答案是砍掉一个类别，或按子系统拆成两张鱼骨。

### 子因刻线

刻线挂在骨长的 **m/6 分数处**（两根子因取 m=2、4；一根取 m=3）：

```
tick_x(k, m) = attach_x(k) - 14 × m        （14 = 84 / 6）
tick_y(k, m) = CY ∓ 24 × m                 （24 = 144 / 6）
```

刻线是从 `(tick_x - 32, tick_y)` 到 `(tick_x, tick_y)` 的 32px 水平线，右端落骨上；标签 `text-anchor="end"`，`x = tick_x - 36`，基线统一 `y = tick_y + 4`。子因标签 ≤8 个汉字（12px 约 96px 宽）——预算内不会撞到同侧相邻骨的斜线，也不会出画布。

图例条按 style-guide 图例条通用规格落（分隔线距内容底 56、基线 +18、色块 16×12、线样 28），本类型四项：类别骨 / 实锤根因 / 子因 / 观测效果。

## 复杂度预算

| 上限 | 规则 |
|---|---|
| 类别骨 | 默认画布 5 根；第 6 根需收窄几何——见几何节 |
| 每骨子因 | 3 |
| 子因总数 | 18 |
| accent 元素 | 2（根因骨+角标、效果盒） |

## 反模式

- **默认画布画超过 5 根骨。** 第 6 根角标裁切画布。要有意识地同步收窄骨距与 `HEAD`，或按子系统拆两张。
- **子因复述类别。** 「发布」骨下挂一条「发布问题」——多了一个节点，没多出信息。
- **零子因的骨。** 空类别是占位符不是发现——删掉这根骨，或等底下真有东西了再画。
- **实锤超过一个根因。** 两个类别都实锤了，那是两张图（或合并成一个原因），不是两根 accent 骨。2-accent 预算撑着「这就是答案」的信号，别稀释它。
- **拿鱼骨画失败时间线。** 按顺序发生的一串事是时间线或时序图——鱼骨是**一个**效果的原因，不是编年史。
- **贴一张带空类别的经典 6M 模板（人 / 机 / 料 / 法 / 测 / 环）。** 类别名来自实际调查，不放一张等着以后填空的通用清单。
- **效果盒写成解决方案。** 「给 p99 加告警」是修复，不是观测。盒子里写看到的东西——症状、测量值、事故——永远不写补救措施。
