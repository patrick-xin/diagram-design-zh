# 看板（Kanban Board）

**最适合**：按状态盘点在制工作——什么在排队、什么在推进、什么卡住了、哪里超了 WIP 限。这是**状态普查，不是流程**：看板**一条连线都没有**。这正是它与泳道（泳道 + 跨道流程，交接是承重边）和流程（有序步骤 + 定向交接）的分界——图里需要任何箭头，它就不再是看板，改用泳道或流程。

## 布局惯例

- **≤5 条等宽竖列**，24px 列沟；列底 `ink @ 0.02` 填充，无列边框。列区 x=0 起排（容器对齐规矩）；示例 4 列 × 232px 恰满 1000 画布。
- **列头带**：列名 sans 14px 600 左对齐；右侧 **WIP 芯片**——矩形小标（`rx=2`，**不许药丸形**；描边 `ink @ 0.40` 0.8px，与 dp 系列芯片同规格）内 mono 9px 写 `n/limit`。在制列必须有限；入口队列与终列无约束，芯片只写裸计数 `n`（攒再多已完成也不构成瓶颈，不装限）。列头带正下方一条全宽发丝线分隔（`ink @ 0.10`，与分区 / 图例线同档——@0.12 是芯片档，别混）。
- **卡片**：节点盒模式 `rx=6`，列宽 −16px 两侧内边距，高 56px，卡间 12px。内容两行：标题中文 sans 12px 500；子标一行 sans 12px `muted`——`票据号 · 经办人` 混排走中文行（如 `DP-214 · 婉琳`）；纯拉丁票据串才许 mono 9px。
- **绘制顺序**：背景 → 列填充 → 列头文字 + WIP 芯片 → 列头发丝线 → 卡片（每张：盒体 → 受阻左缘条（若有）→ 标题 → 子标）→ 图例。

## 卡片四态——本类型的语义词汇

每张卡恰好处于四态之一；卡数够时就该把四态全用上：

| 状态 | 填充 | 描边 | 附加 |
|---|---|---|---|
| `default` 常规 | `paper` | `ink` 细描边 | — |
| `blocked` 受阻 | `accent-tint` 淡染 | `accent` 实色虚线 `4,4` | 左缘 4px `accent` 竖条 |
| `waiting` 等待外部 | `ink @ 0.02` | `ink @ 0.20` 虚线 `4,3` | — |
| `done` 完成 | `ink @ 0.05` | `muted` | — |

四态直接复用 SKILL §6 节点类型表的安全 / 可选 / 存储处理（`security` → 受阻、`optional` → 等待、`store` → 完成）——看板不发明新填充，只复用系统既有语义。

## 超限列

某列卡数 `n` 超过芯片所标 `limit` 时，该 WIP 芯片描边与文字转 `accent`。这一枚超限芯片 + 一张受阻卡 = 本类型全部 2 个 accent 预算——别处不许再花。无超限也无受阻的板子就不带焦点色，不硬造。

## 复杂度预算

- ≤5 列；每列 ≤4 卡；全板 ≤12 卡。
- accent ≤2（超限芯片计 1、受阻卡计 1）。
- 单列超预算 → 积压聚合成一张计数卡（子标写 `+14 更多`），不逐条列完。

## 反模式

- **卡与卡之间画箭头**——板显状态不显流；流要看就改用泳道或流程。
- 单列超过 4 张卡不聚合——列会滚出画布。
- **一人一卡**——那是穿看板皮的组织架构图。
- **在制列不标 WIP 限**——限是这个类型一半的意义；工作流过的列没有限就看不出超编。入口队列和终列例外（裸计数）。
- **每张受阻卡都上焦点色**——一两张受阻是信号，一列 accent 是噪声。
- **「已完成」列无界增长**——封顶并在子标注明归档点，否则它变成第二个待办。
- 药丸形 WIP 标签——芯片是 `rx=2` 矩形，与节点盒类型角标同源；药丸是另一套设计语言的徽章。
