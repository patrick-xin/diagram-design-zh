# 金字塔 / 漏斗（Pyramid / Funnel）

**最适合**：需求层级、优先级排名、价值金字塔、转化漏斗、内容重要性堆叠。

## 两种朝向——选一种

- **金字塔**（尖朝上）：顶窄 = 最重要 / 最稀有 / 最有价值；底最宽 = 基础。
- **漏斗**（尖朝下）：窄端 = 转化结果（最小人群）；顶最宽 = 受众。

一张图里不许混用两种朝向。

## 布局惯例

- 4–6 层。每层是 SVG `<polygon>` 四点梯形；**塔尖是单一三角形**，不是梯形。
- **等高等坡**：每层等高（56–72px），每侧收窄量 = 层高（45° 等坡），塔尖两条斜边与下层同坡——这样才是一座金字塔，不是一堆散梯形。
- 宽度从底到顶（金字塔）或从上到下（漏斗）线性递减。**画真实漏斗数据时宽度必须诚实**（与数量 / 百分比成比例）；数量级悬殊的金字塔（90% vs 0.1%）用等距台阶 + 右缘数字标注，不把 0.1% 画成一条缝。
- 每层配：
  - **层名**：梯形内居中，中文 sans 12–14px 600，全图统一一档。
  - **副标**：层名下方，mono 10px（中文不低于 10px）。
  - **右缘侧注**（可选）：金字塔放占比 / 频次（mono 9px `soft`，塔尖侧注用 `accent`）；漏斗把流失率放这里（`−40%`）。
- 填充：两层方案二选一——① 按层递增的 ink 淡染梯；② 全部 `paper-2` 底 + 发丝分隔线（更干净）。全图统一。
- 描边：层间 1px 发丝线；外轮廓 1px `muted` 或 `ink`。
- **accent 只给一层**：金字塔的塔尖、漏斗的转化层、或关键瓶颈层。
- 可选左缘轴箭头 + 旋转标注（`rotate(-90)`，中文 sans 10px · 0.2em，箭头用图形不进文字）：金字塔标「更稀有 ↑」方向，漏斗标「逐层流失 ↓」。
- 塔底一句脚注总结基座与塔尖的关系（居中、`muted` 12px）——金字塔的灵魂句。

## 反模式

- 7 层以上（不可读——压缩或拆图）。
- 层与层坡度不一致、塔尖画成梯形——形状散掉，读不出「金字塔」。
- 非层级数据硬画金字塔（改树形图或柱状图）。
- 宽度造假（流失不均却画成等距）。
- accent 落在底层（稀释「塔尖 = 稀有」的信号）。
