# 层级堆叠（Layers）

**最适合**：OSI 模型、CSS 级联、上下文层级、技术栈分层、抽象层次、存储层级。

## 布局

- 横向条带纵向堆叠。每层是同 x、同宽的整幅矩形，共 4–6 层。
- 层高 56–72px，带宽 868、内容右缘 960，画布宽 1000、高按内容底取整到 40 的倍数。
- 每行从左到右三段：
  1. **序号角标**（`L3`、`07`）——纯拉丁走 eyebrow-latin（mono 7–8px）。
  2. **层名**——容器级元素可到 14px · 600（sans），略居中偏左。
  3. **子标注**（右端对齐）——按语言选行：中文走 sans 12px，纯拉丁技术串走 mono 9px。
- 层间分隔：1px 发丝线 `ink @ 0.10`；外轮廓 1px 发丝线同档（整幅上下边）。
- 填充：`paper` 与 `ink @ 0.02` **交替**（焦点层用 accent 淡填充 + accent 描边另算）。**不用色相区分层级**——系列五色有限而层数不可控，容器色交替任意层数可扩展（2026-08-22 拍板）；`paper-2` 垫底已废除。
- 左侧留白（堆叠外）放**方向指示**：一条竖标尺线（`ink @ 0.30`）+ 端点箭头 + 标签——中文走分区标签档（sans 10px · 500 · 0.3em · muted），纯拉丁走 eyebrow-latin。
- **标尺几何**：竖线在堆叠左缘左侧 64px（给居中标签留宽），y 两端与堆叠上下缘**精确对齐**（示例：线 y 24→344，堆叠上下缘 24→344，零偏差）；箭头落在语义方向那一端（底边咬住线端点、尖朝外）。**两个标签以线为中心水平居中**（`text-anchor="middle"`），分别在线顶上方与线底下方；顶标签上方留 ~12 单位，不够就把标尺与堆叠整体下移保顶贴。self_check 几何层会校验两端对齐，偏差 >4px 告警。
- 焦点色落在**恰好一层**（描边 + 浅 tint 底）——瓶颈层、成本层、正在讨论的那层。
- 底部为标准**图例横条**（锚 = 最下内容元素底 + 56——带标尺端点标签时**含标签**为锚，不只量堆叠底；「图例」mono 10px · 0.1em 基线 +18、焦点层样本块 16×12）。需要一句编辑性点评时，以 callout（serif italic 14px · muted）接在图例项后**同基线**随行，全图至多一条——图例行不必只有图例。

## 反模式

- 层级关系其实不成立（数据不分上下级）——改用泳道或架构图。
- 序号跳号（L3 与 L5 之间缺 L4 且不解释）。
- 每层一个颜色——层级感直接消失；系列色同理不可用（色板有限、层数不可控）。
- 层高无理由地不一致。
- 标尺线两端与堆叠上下缘不咬合（悬空、越界或只盖一半）——坐标落在 4px 网格上不等于几何关系正确。
