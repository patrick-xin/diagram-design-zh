# 层级堆叠（Layers）

**最适合**：OSI 模型、CSS 级联、上下文层级、技术栈分层、抽象层次、存储层级。

## 布局

- 横向条带纵向堆叠。每层是同 x、同宽的整幅矩形，共 4–6 层。
- 层高 56–72px，宽度通常 800–880px，放在 1000px 宽的 viewBox 里。
- 每行从左到右三段：
  1. **序号角标**（`L3`、`07`）——纯拉丁走 eyebrow-latin（mono 7–8px）。
  2. **层名**——容器级元素可到 14px · 600（sans），略居中偏左。
  3. **子标注**（右端对齐）——按语言选行：中文走 sans 12px，纯拉丁技术串走 mono 9px。
- 层间分隔：1px 发丝线 `rgba(41,49,79,0.10)`；外轮廓 1px ink 或 muted。
- 填充二选一并全图保持一致：相邻浅色交替（`paper` / `paper-2`），或全 `paper` + 发丝线。
- 左侧留白（堆叠外）放**方向指示**：一条竖标尺线 + 端点箭头 + 标签——`抽象 ↑`、`延迟 ↓` 中文走 eyebrow-zh（sans 12px · 0.3em）；纯拉丁（`packets ↓`）走 eyebrow-latin。
- **标尺几何**：竖线在堆叠左缘左侧 40px，y 两端与堆叠上下缘**精确对齐**（示例：线 y 80→400，堆叠上下缘 80→400，零偏差）；箭头落在语义方向那一端（底边咬住线端点、尖朝外），标签贴在箭头端外侧。self_check 几何层会校验两端对齐，偏差 >4px 告警。
- 焦点色落在**恰好一层**（描边 + 浅 tint 底）——瓶颈层、成本层、正在讨论的那层。
- 需要一句编辑性点评时，用 callout（serif italic 14px）放在堆叠下方，全图至多一条。

## 反模式

- 层级关系其实不成立（数据不分上下级）——改用泳道或架构图。
- 序号跳号（L3 与 L5 之间缺 L4 且不解释）。
- 每层一个颜色——层级感直接消失。
- 层高无理由地不一致。
- 标尺线两端与堆叠上下缘不咬合（悬空、越界或只盖一半）——坐标落在 4px 网格上不等于几何关系正确。
