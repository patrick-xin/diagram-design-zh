# 皮肤：新中式（墨 · 印 · 签）

装载后，本文件是本皮肤色彩与专属元素（钤印 / 题签 / 朱批）的唯一权威。连接线纪律、4px 网格、密度预算、三字体栈、字号下限、混排规则按 SKILL.md 原文执行。

---

## 1. 色板

| 角色 | 值 | 名 |
|---|---|---|
| `paper` | `#f6f2e9` | 宣纸 |
| `paper-2` | `#ede7d9` | — |
| `ink` | `#322f2a` | 玄墨 |
| `muted` | `#5a564d` | 重墨 |
| `soft` | `rgba(50,47,42,0.55)` | 淡墨 |
| `rule` | `rgba(50,47,42,0.20)` | 清墨 |
| `accent` | `#c3272b` | 朱砂 |
| `accent-tint` | `rgba(195,39,43,0.07)` | — |
| `link` | `#3f5266` | 黛蓝 |

**墨分五色（硬规则）**：所有中性色必须是玄墨 `#322f2a` 的明度/透明度阶——浓淡之分，没有色相之别。禁止蓝灰、纯灰等第二色相的中性色混入。

**对比度（对宣纸）**：玄墨 11.9:1 · 重墨 6.5:1 · 朱砂 5.2:1 · 黛蓝 7.2:1——文本级元素全部 AA，朱砂可直接用于文字。淡墨 3.2:1，只作三级标签与描边，不作正文。

## 2. 钤印（焦点强调，替代 accent-tint 染色）

焦点节点**不上色、不加 accent 描边**——保持正常节点处理，改在节点右上角内侧钤一枚印：

- 印面：16×16 方形，`rx=2`，fill 朱砂
- 印文：单个表角色的汉字（核 / 枢 / 要 / 重），`paper` 色，serif 10px，居中；拉丁标签用 ≤3 字符大写 mono 7px
- 预算与 accent ≤2 相同：全图钤印 ≤2 枚；钤了印的节点不得再有任何着色强调——**强调机制只能有一个**
- 朱砂的第二种合法用法：主流程连接线（细线 1.2）。此外朱砂不得大面积出现

```svg
<rect x="{节点右-24}" y="{节点顶+8}" width="16" height="16" rx="2" fill="#c3272b"/>
<text x="{印中心x}" y="{印中心y+3.5}" fill="#f6f2e9" font-size="10"
      font-family="'Noto Serif SC', 'Songti SC', serif" text-anchor="middle">核</text>
```

## 3. 题签（分区/容器标签，替代顶部横排角标）

竖排纸条骑在分区右边界线上，像线装书封面的题签：

- 纸条：宽 20，高 = 字数×14+10，fill `paper`，stroke `rgba(50,47,42,0.18)` 0.8，rx=2
- 文字：中文 sans 12px 500，逐字竖排（每字一个 `tspan`，`dy=14`），fill `muted`，`text-anchor="middle"`
- 位置：纸条水平中心压在分区右边界线上（骑线，像书签）；连接线从纸条背后穿过——先画线，后画签
- 拉丁分区名不用题签（竖排拉丁丑），保持横排 mono 角标

```svg
<rect x="{边界x-10}" y="{y}" width="20" height="{字数*14+10}" rx="2"
      fill="#f6f2e9" stroke="rgba(50,47,42,0.18)" stroke-width="0.8"/>
<text x="{边界x}" y="{首字基线}" fill="#5a564d" font-size="10" font-weight="500"
      font-family="'MiSans', 'Noto Sans SC', 'PingFang SC', 'Microsoft YaHei', sans-serif"
      text-anchor="middle">生<tspan x="{边界x}" dy="14">产</tspan><tspan x="{边界x}" dy="14">环</tspan><tspan x="{边界x}" dy="14">境</tspan></text>
```

## 4. 朱批（旁注，替代斜体 callout）

朱砂小字眉批 + 细引线，全图 ≤1 条，宁缺毋滥：

- 文字：serif 12px 400，朱砂，≤12 字
- 引线：从注释下方垂直引到目标边缘，朱砂、0.8 宽、60% 不透明度

```svg
<text x="{x}" y="{y}" fill="#c3272b" font-size="10.5"
      font-family="'Noto Serif SC', 'Songti SC', serif">外部依赖 · 限时 2s</text>
<line x1="{x+4}" y1="{y+6}" x2="{x+4}" y2="{目标顶-4}" stroke="#c3272b" stroke-width="0.8" opacity="0.6"/>
```

## 5. 沿用的规则（SKILL.md 已定义，本文件不重定义）

- 三字体栈、字号下限、字距体系、混排规则——SKILL.md §7 全文适用
- 连接线规则（正交肘线、遮罩、跳线）、4px 网格、节点 ≤9
- 页面结构（eyebrow / serif 标题 / frame）、单文件输出契约、a11y slug 规则
- 背景无纹理（宣纸的干净就是纹理，不加纸纹、不加点阵）

## 6. 反模式（本皮肤专属，违反 = hard fail）

- **红金搭配**——一步掉进伪中式
- 龙凤 / 祥云 / 回纹 / 水墨飞白等纹样装饰
- 隶书 / 行楷 / 魏碑 / 华文行楷做标题——三栈之外的字体一律不准引入
- 钤印超过 2 枚；或钤印之外又给焦点节点染色
- 中性色出现第二色相
- 整页朱砂化——朱砂贵在小而密
- 中文全用题签、拉丁也竖排

## 7. 漆器暗变体（`xinzhongshi-dark`，reskin 定制表）

黑地漆器风的暗色变体：墨黑底、宣纸色字、朱砂焦点、描金走线。仅以 `scripts/skins/xinzhongshi-dark.json` 存在——值级换肤用，不含钤印 / 题签结构（要完整结构效果按本文件生成时规则画，再取本表值）。

| 槽位 | 值 |
|---|---|
| paper / paper-2 | `#16130e` / `#201b12` |
| ink / muted | `#efe7d6` / `#c8bda3` |
| soft | `rgba(239,231,214,0.50)` |
| accent | `#e85f4e`（亮朱砂） |
| link | `#d8b66a`（描金——借 link 槽位承载） |

- 焦点取**亮朱砂**而非深朱砂：语义五色里的安全红（`#b85450` / 深档 `#bf6561`）换皮不换义、跨皮肤恒定，深朱砂与其色距不足会混淆焦点与「安全」语义——亮一档明度既保朱砂身份又拉开距离（色距 46 / 49，gate 阈值 40）。
- 深色档换基规则照旧适用（ink 基 rgba(239,231,214,X)、焦点 tint 提档 0.10、白盒换 paper 色）。
- 用法：`python3 scripts/reskin.py --skin xinzhongshi-dark <成品.html> -o <输出>.html`
