# 时序图（Sequence）

**最适合**：请求/响应流、协议交换、多角色随时间的交互、API 调用链路、事故复盘、带分支的认证 / token 刷新路径。

## 布局

- 参与者 = 顶部一排盒子。
- **生命线**：从每个参与者盒底垂到图底的虚线竖线。
- 消息 = 生命线之间的水平箭头；时间自上而下推进。
- **激活条**：生命线上的窄矩形（`w=8`，muted 填充 @ 0.06，0.8 细描边），覆盖该参与者持有控制的区间。嵌套调用就叠放。
- 自消息：短 U 形回路回到同一条生命线；标签放回路右侧。
- 返回消息：**虚线**描边 + **实心**箭头（永远不用空心）。默认 muted；多跳配对时可跟随发起调用的颜色。主线成功可用实线焦点色（见消息种类）。
- 焦点色落在主成功响应或头条消息上——一条，最多两条。参与者的焦点描边**不占**焦点预算。
- 流程**分支**时（token 有效/无效、重试、可选步骤），画**组合片段框**——不许发明游离的 if/else 箭头堆。

## 消息种类

| 种类 | 描边 | 箭头 | 何时用 |
|---|---|---|---|
| 调用（同步） | 实线 muted 或 `link` 蓝 | 实心 | 期望得到回复的请求 |
| 返回 | **虚线** muted（或跟随调用色） | 实心 | 同步调用的回复——永远不画实线 |
| 异步 / 发后不管 | 虚线 muted | **空心** | 埋点、事件、单向通知 |
| 主线成功 | 实线 `accent`（≤1–2 条） | `accent` 实心 | 只给主 happy-path 响应 |

### 空心箭头（异步）

在 `<defs>` 里定义一次，只用于发后不管：

```svg
<marker id="arrow-open" markerWidth="8" markerHeight="6" refX="7" refY="3" orient="auto">
  <polyline points="0 0, 8 3, 0 6" fill="none" stroke="#565e7e" stroke-width="1.2"/>
</marker>
```

不要给空心箭头填色——镂空头就是异步信号。返回消息即使虚线也保持**实心**箭头。

## 组合片段（`alt` / `opt` / `loop`）

用矩形**框**只罩住参与该分支的生命线。操作符标签用 mono、大写，放框左上角的小标签页里。框内时间仍然自上而下。

### 框基元（共用）

```svg
<!-- 片段框：淡墨水洗 + 细线。标签页在左上角。 -->
<rect x="X" y="Y" width="W" height="H" rx="4"
      fill="rgba(41,49,79,0.02)" stroke="rgba(41,49,79,0.20)" stroke-width="1"/>
<!-- 操作符标签页 -->
<rect x="X" y="Y" width="40" height="16" rx="2"
      fill="#ffffff" stroke="rgba(41,49,79,0.20)" stroke-width="1"/>
<text x="X+20" y="Y+12" fill="#565e7e" font-size="8"
      font-family="'Sarasa Mono SC', ui-monospace, monospace" text-anchor="middle"
      letter-spacing="0.12em">ALT</text>
```

### 操作符

| 操作符 | 区域数 | 分隔线 | 守卫标签 |
|---|---|---|---|
| `opt` | 1 | 无 | 标签页下方 `[若条件成立]`（mono 8px；含汉字用 sans 12px） |
| `alt` | **最多 2** | 跨框虚线水平细线 | 区域 1 放 `[守卫]`；区域 2 放 `[否则]` 或第二个守卫 |
| `loop` | 1 | 无 | 标签页下方 `[逐项处理]` / `[重试 ≤ 3]` |

### 守卫 + 分隔线基元

```svg
<!-- 守卫：框内左对齐 -->
<text x="X+12" y="GUARD_Y" fill="#565e7e" font-size="8"
      font-family="'Sarasa Mono SC', ui-monospace, monospace" letter-spacing="0.04em">[token valid]</text>

<!-- alt 区域分隔线 -->
<line x1="X+8" y1="DIV_Y" x2="X+W-8" y2="DIV_Y"
      stroke="rgba(41,49,79,0.20)" stroke-width="1" stroke-dasharray="4,3"/>
```

### 片段布局规则

- 框左右从最外层参与生命线的中心再向外留 ≥12px（激活条保持在框内）。
- 区域内相邻消息 y 层级间隔 ≥24px（4px 网格）。
- 守卫放在标签页下方约 20px 内；该区域第一条消息距守卫基线 ≥24px。
- 分隔线 y 落 4px 网格；与上下消息各留 ≥16px 净空。
- 嵌套片段：**最多 1 层**。宁可拆两张图。
- 默认每图**一个**片段。第二个只在两者都低于复杂度预算时允许。
- 焦点色在整个图里只落在**一条**主线成功消息上（通常是第一个 `alt` 区域内的 happy-path 返回，或 loop 外的最终成功）。两个 `alt` 分支不许都上焦点色。

### 范围外（不要发明）

- `par`、`critical`、`break`、`ref` 及其他 UML 操作符。
- 参与者创建/销毁、found/lost 消息、时长计时条。

## 复杂度预算（时序专属）

- 生命线 ≤5。
- 消息（箭头）≤12。
- 组合片段 ≤1（默认硬规则）；2 只在各自都是单区域 `opt`/`loop` 时允许。
- `alt` 区域 ≤2。
- 片段嵌套 ≤1 层。
- 焦点色元素 ≤2（带片段的图建议 1）。

超了就拆：总览（happy path）+ 细节（失败 / 刷新路径）。

## 生命线基元

```svg
<line x1="CX" y1="TOP" x2="CX" y2="BOTTOM"
      stroke="rgba(41,49,79,0.20)" stroke-width="1" stroke-dasharray="3,3"/>
```

## 激活条基元

```svg
<rect x="CX-4" y="TOP" width="8" height="H"
      fill="rgba(41,49,79,0.05)" stroke="#565e7e" stroke-width="0.8"/>
```

## 消息标签

- 含汉字：sans 12px · 500 · 0.12em，`paper` 不透明遮罩，与箭头保持 6–10px 净空（标签放箭头上方）。
- 纯拉丁技术串（`POST /v2/login`、`JWT`）：mono 8–9px · 0.04–0.06em，同样加遮罩。
- 标签不许压在第三条生命线上——缩词或把 y 挪进空档。

## 反模式

- 消息箭头朝上（时间倒流——绝不）
- 激活条永远不关
- 标签压在别人的生命线上
- 用泳道代替生命线（另一种语法，用泳道图）
- if/else 画成两堆没有片段框的游离箭头
- `alt` 里嵌 `alt`（拆两张图）
- 片段操作符标签写成 sans——必须 mono：`ALT` / `OPT` / `LOOP`
- 两个 `alt` 分支都上焦点色
- 框罩住了框内没有消息的参与者
- 异步发后不管用实心箭头（用空心）
- 返回消息用空心箭头（返回 = 虚线 + 实心）
