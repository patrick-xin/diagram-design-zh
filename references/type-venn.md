# 维恩图（Venn / Set Overlap）

**最适合**：概念 / 领域的交集、类目间的共性属性、「A 与 B 在哪相遇」、ikigai 式三环框架（想做 × 能做 × 值得做）。

## 布局惯例

- **优先 2 或 3 个圆。** 4 个以上放弃（不可读——改用矩阵）。
- 圆描边：1px 发丝线，各集合一档（`ink` / `muted` / `soft`）。
- 圆填充：极低透明度淡染，三档同 @ 0.05（`ink` / `muted` / `soft` 各随其基）。淡染在交叠区自然叠深。
- 半径：集合大小可比时等径；大小确实悬殊时按比例。不为好看把悬殊画成等径。
- **集合名放圆内专属耳叶**（不与其他圆交叠的区域），经典维恩读法。中文 sans 14px 600 居中，可带 mono 10px 副标。文字块整体收在圆内、距描边 ≥8px——下环的耳叶是斜的，标签要往圆心方向收，别照抄对角坐标让副标伸出圈外。耳叶实在放不下时才移到圆外，且绝不压描边线。
- **两两交集不逐个命名**——只标三个集合名 + 一个焦点。交集标签一多，读者分不清主次，生成端也容易画乱。示例只打这个简单样式；用户有复杂交集需求，让他直接向 agent 提。
- **焦点 = 三环公共区填 `ink` 实色**——链式 clipPath 隔离（裁到 A，再裁到 B，最后用 C 圆填色）。焦点标签反白：白 14px 600 + 0.72 白 mono 副标。这是维恩图里唯一允许的实色块；`accent` 仍留给线条类强调，不在圆内铺大色块。深色档：淡染按 ink-α / muted-α 基换色（soft 环并 muted-α 基，不立 soft-α 新例）；交集实色反转亮块（ink 深色档）+ 深字（副标 0.72 深字版）。
- 圆心与半径落在 4px 网格上。

## 反模式

- 有区域没标签——读者分不清哪个集合是哪个。
- 交集是主题却画成不相交的圆。
- 标签或副标伸出圈外（下环斜耳叶最常犯）——按弦宽算余量，整体往圆心收。
- 两两交集逐个命名——主次全无，图面和语义一起糊掉。
- 集合大小明显悬殊却画等径（不诚实）。
- 焦点交集不填实色、只给彩色文字——焦点信号太弱，一眼找不到甜点位。
- 标签骑在圆描边线上（不可读）。
- 2–3 个圆够用却画 4 个以上。
