# 飞轮 / 循环（Loop）

**最适合**：增强回路、增长飞轮、反馈循环、运营循环——最后一步喂回第一步、且每圈向一个共享中心沉淀状态。用 Loop 的前提是读者必须**同时看到两种运动**：工作沿环顺时针推进，每一圈把持久状态写回同一个中心。

路径会终止、分支导向结局、或实际上回不到第一步的，用**流程图**。中心不沉淀共享状态的，用普通环形排列即可。**判别信号：虚线写回辐条**——去掉它，这张图只是个摆成圆圈的流程。

本类型是**参数化**的：§1 的输入决定站点数、角度、交点、连接线路径和 viewBox 边界。相同输入必须产出相同几何。

---

## 1. 输入——参数契约

```yaml
title: "开发者工具的增长飞轮"
subtitle: "每一圈都把沉淀写回社区知识库"

hub:                        # 恰好一个
  name: "社区知识库"
  sublabel: "每一圈都在变厚"

stations:                   # 5..8，从顶部起顺时针
  - { name: "免费产品",   sublabel: "cli · 模板库",     spoke_label: "写入" }
  - { name: "内容触达",   sublabel: "教程 · 案例展示" }
  - { name: "注册激活",   sublabel: "首跑 5 分钟出结果" }
  - { name: "付费转化",   sublabel: "pro · 团队版订阅", focal: true }
  - { name: "收入再投入", sublabel: "招人 · 做深功能" }
  - { name: "产品变好",   sublabel: "口碑 · 自然推荐" }

station_w: 160
station_h: 64
hub_w: 200
hub_h: 104
radius: 240
margin: 64
```

**预算（硬规则）**：**5–8 个站点 + 恰好 1 个 hub**。超过 8 个站点，把主题拆成一张总览 Loop 加若干细节图。恰好一个 hub——两个 hub 的"循环"是两个系统，拆成两张图。最多一个站点 `focal: true`；没有值得强调的焦点时，零个也合法。

站点顺序是语义的。`stations[0]` 是顶部站点，之后顺时针排列。最后一个站点总是连回站点 0；如果这个回环是假的，改用流程图。

## 2. 布局数学——确定性几何

SVG 坐标系，y 向下为正。设 hub 中心 `C = (cx, cy)`，站点数 `N`，环半径 `R`，站点半宽 `a = station_w/2`、半高 `b = station_h/2`，hub 半宽 `A = hub_w/2`、半高 `B = hub_h/2`。

### 2.1 站点中心

零基站点 `k`：

```text
theta_k = -90° + k · (360° / N)
u_k     = (cos theta_k, sin theta_k)
P_k     = C + R · u_k

station_center_x(k) = cx + R · cos(theta_k)
station_center_y(k) = cy + R · sin(theta_k)
station_x(k)        = station_center_x(k) - station_w/2
station_y(k)        = station_center_y(k) - station_h/2
```

站点 0 在顶部，`k` 增大即顺时针移动。站点矩形按理想几何算完后取整到最近的 4px 网格点，成对站点取整保持对称。圆/盒交点保留 3 位小数——保证每段弧都落在同一个圆上。

### 2.2 实线环流端点

环连接线从站点 `k` 画到 `j = (k + 1) mod N`，是站点圆自身上的圆弧段：每段用同一个圆心 `C`、半径 `R`、顺时针 sweep。站点盒打断圆；连接线从圆离开源盒的顺时针出口开始，到进入目标盒的逆时针入口之前结束，使箭头尖端正好落在目标描边上。

对站点 `k` 的四条边求圆/矩形交点。竖直边 `x = x_e`：

```text
y = cy ± √(R² − (x_e − cx)²)
```

只保留 `y` 落在该边范围内的候选。水平边 `y = y_e`：

```text
x = cx ± √(R² − (y_e − cy)²)
```

只保留 `x` 落在该边范围内的候选。两个幸存交点按绕 `C` 的归一化极角分类：

```text
q_entry(k) = theta_k 逆时针侧紧邻的圆/盒交点（进入站点前）
q_exit(k)  = theta_k 顺时针侧紧邻的圆/盒交点（离开站点后）
```

发射目标端点前先补偿箭头尖端。基准箭头（`refX=7`、多边形尖端在 `x=8`）配环流描边 1.2 时，`marker_overhang = 1.2`：

```text
phi_entry = atan2(q_entry(j).y − cy, q_entry(j).x − cx)
phi_end   = phi_entry − marker_overhang / R
q_end     = C + R · (cos(phi_end), sin(phi_end))

M q_exit(k).x q_exit(k).y
A R R 0 0 1 q_end.x q_end.y
```

large-arc 标志取 `0`（相邻站点间隙小于 180°）；SVG 坐标系里顺时针运动 sweep 恒为 `1`。箭头悬出量补完最后 1.2px 到 `q_entry(j)`，落在盒边上而不压穿描边。从站点 `N−1` 回到站点 0 的闭合连接线用同一公式。

Loop 的圆环弧是 SKILL.md §8 规则 1（正交肘线）的**文档化类型特例**。环上永远不混三次曲线、直线或圆角正交段：可见的几段间隙必须读作同一个连续圆的片段。

### 2.3 虚线写回辐条端点

每根辐条从站点内缘指向 hub。用同一套射线/盒交点公式，作用在径向单位向量 `u_k` 上：

```text
box_distance(v, half_w, half_h) = min(half_w / |v.x|, half_h / |v.y|)
                                  # 分母为零的项忽略

d_station  = box_distance(u_k, a, b)
d_hub      = box_distance(u_k, A, B)
marker_gap = 6                    # 4..8px；6 为基准值

spoke_start(k) = P_k − d_station · u_k
hub_edge(k)    = C   + d_hub     · u_k
spoke_end(k)   = C   + (d_hub + marker_gap) · u_k
```

箭头从站点指向 `C`，加 `marker_gap` 使终点停在 hub 边界外侧——浅色箭头停在 hub 描边之前，不撞上去。径向辐条是对"禁止斜向直线连接"的类型特例：必须是真半径、互不交叉、只碰自己的源站点和 hub。

站点子标签已经说清写回内容时，辐条标签可省。要用则按 arrow-label 角色（按语言选行），**骑在辐线上居中**、配不透明 `paper` 遮罩盖线——家族连线标签的统一姿势（文字不与线重叠，遮罩负责断线）。只标精选的少数，不要硬把六个标签塞进 hub 光环。

### 2.4 viewBox 尺寸

viewBox 必须容纳全部站点矩形、外侧环弧、箭头，以及至少 `margin` 的呼吸空间：

```text
left   ≤ cx − R − station_w/2 − margin
right  ≥ cx + R + station_w/2 + margin
top    ≤ cy − R − station_h/2 − margin
bottom ≥ cy + R + station_h/2 + margin

viewBox_w = right − left
viewBox_h = bottom − top
```

核对上下限时把圆的极值点 `cx ± R`、`cy ± R` 连同站点边界和箭头余量一起算。绝不压缩画布直到站点描边、箭头或环弧被裁切。**画布宽 1000 定死**（SKILL 画布基线），高度向上取整到 40 的倍数。六站点基准例：viewBox `0 0 1000 640`、`C=(480,272)`、`R=240`、站点 `160×64`、hub `200×104`。

## 3. 视觉语法

| 元素 | 处理 |
|---|---|
| 站点 | 标准节点：`paper` 底 + `ink` 描边 `radius-md`；名 sans 12px · 600，子标签 10px（含汉字下限；纯拉丁走 mono 栈）。文字垂直居中：名/副标基线 = 盒顶 +28 / +48（盒高 64 时，中心 −4 / +16，与 hub 同法） |
| hub | **全图唯一深色元素**：`ink` 填充 + `paper` 文字，比站点大一圈；名 14px · 600 |
| 焦点站点（≤1） | `accent-tint` 底 + `accent` 描边；站点名可用 `accent` |
| 环流 | 站点圆上的圆弧 `A R R 0 0 1`，实线 `muted` 1.2，目标端默认箭头；只顺时针 |
| 写回辐条 | `soft` 虚线 `stroke-dasharray="4,3"`（虚线闭集），配 `soft` 箭头，整体降一级强调 |
| 辐条标签 | arrow-label 角色（按语言选行），骑线居中 + 不透明 `paper` 遮罩 |
| 图例横条 | 分隔线距最下站点底 56、右缘贯通 0→1000；样本与图内实物一致（环流 1.2 带箭头、辐条 4,3 虚线、焦点 tint 块、hub 实色块） |

绘制顺序：背景（或可选点阵）→ 环箭头 → 虚线辐条 → 辐条标签遮罩与文字 → 站点盒 → hub → 文字。节点盖住微观出头，每个有意的终点仍落在边上。

hub 不是第七个流程步骤。它是**沉淀的共享状态**：记忆、标准、证据、策略、共享运营记录。文案 = 一个名称 + 一句短副标。

## 4. 连接线规则（强制）

SKILL.md §8 全部适用，除两个 Loop 专属连接原语：圆环弧（§2.2）与径向直辐条（§2.3）。对本类型，它们替代规则 1：

- 环箭头是同半径圆弧、实线、顺时针。每条路径都是 `A R R 0 0 1`；目标箭头落在站点边缘，没有任何连接线终止在中心点。
- 辐条必须虚线、指向内。实线辐条会抹掉"运营流 vs 写回"的视觉区分。
- 标签骑线居中、不透明 `paper` 遮罩断线——文字不与线重叠。
- 环连接线与辐条互不重叠。环路径留在 hub 外；辐条各占一条径向路线。
- 同一站点边要出两根辐条时，附着点按 §5 公式扇出、间距 ≥12px。正常 Loop 每站一根；第二根只在语义无法合并时用。
- 环路若会穿过 hub，增大 `R` 或拆图。不要让流程穿过共享状态，也不要换成正交路线。

## 6. 复现清单

1. 站点 5–8 个，hub 恰好一个。
2. 站点 0 在 −90°；其余按等距 `360/N` 步进顺时针。
3. 每条实线环箭头用同一 `R` 的 `A R R 0 0 1` 连接相邻站点；最后一条回到第一条。
4. 每个环箭头落在站点边缘，不是中心。
5. 每根虚线辐条从站点内缘出发，停在 hub 描边外 `marker_gap` 处。
6. 环连接线留在 hub 外；辐条不交叉、不重叠。
7. 最多一个站点用 `accent-tint` + `accent`；深色 `ink` 填充只属于 hub。
8. 辐条标签（如有）骑线居中 + arrow-label 角色 + 不透明遮罩。
9. viewBox 容纳站点盒、描边、弧线、箭头和边距，无裁切；**宽 1000 定死**。
10. 图例横条：分隔线距最下站点底 56、右缘贯通 0→1000；样本（线宽、虚线、箭头、色块）与图内实物一致。

## 7. 反模式

| 反模式 | 为什么坏 / 纠正 |
|---|---|
| 两个 hub | 两个沉淀状态 = 两个系统。拆成两张图。 |
| 实线辐条 | 看起来像主流程，杀掉虚线写回信号。用 `soft` 虚线 4,3 写回。 |
| 站点角度无理由地不均 | 环失去"单一运营节奏"的读感。除非有明确的阶段分组，用等距 `360/N`。 |
| 环上混圆弧 + 正交段 | 环变成圆角矩形。每段必须是同半径圆弧，环才读作一个连续的圆。 |
| 连接线穿 hub | 流程和状态混在一起。环走外圈或加大半径。 |
| 多个 accent 站点 | 焦点信号消失。最多一个焦点站点。 |
| 超过 8 个站点 | 标签和辐条挤爆 hub 光环。拆成总览 + 细节。 |
| 转不回来的"圈" | 那是摆成圆形的流程图。改用流程图画出真实终点。 |
