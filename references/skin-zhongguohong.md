# 中国红（政务红）皮肤

单色相红的政务风皮肤：整套 token 从默认皮肤换为红系（mono——`link` 与 `accent` 同为朱红，靠 tint 底与线型区分），排版纪律（字号坡道 / 字距 / 4px 网格 / 正交圆角连线）与默认皮肤完全一致，只有色值不同。对比度经 tonex（MD3）实算，134 对 WCAG AA 全过。

## 启用条件（任一满足即启用）

1. 用户点名：中国红 / 政务红 / 红色主题 / 红头文件风。
2. 题材本身是党政机关、政务公开、国企汇报、党建场景。

**不启用**：普通企业图哪怕品牌色是红——那走 onboarding 品牌定制（写回 token），不上本皮肤。判定看用户自述，不看内容类型。

## Token（浅色档，暂无深色档）

| 角色 | 值 | 说明 |
|---|---|---|
| `paper` | `#fff8f7` | 暖白纸面 |
| `paper-2` | `#f6edec` | 容器底 |
| `ink` | `#522522` | 主文本、主描边 |
| `muted` | `#87504c` | 次文本、默认箭头 |
| `soft` | `#b18b88` | 三级文本 |
| `rule` | `rgba(82,37,34,0.12)` | 发丝线 |
| `accent` | `#b11821` | 焦点（≤2 处），也是 `link`——单色相 |
| `accent-tint` | `rgba(177,24,33,0.08)` | 焦点底色 |
| `link` | `#b11821` | HTTP/API 边；与 accent 同值，靠「细线无底」与「焦点节点 tint + 描边」区分语义 |

backend 节点白底 `#ffffff`、store `ink @ 0.05`、external `ink @ 0.03` 等节点语义处理沿用默认皮肤规则，只把 ink/accent 基色换为本表值。

## 纪律

- 一个焦点的纪律不变：accent ≤2 处；红 tint 底只给焦点节点。
- 反模式：红金搭配（伪政务）、整页红底、muted 调成粉色、给非焦点元素上朱红。
- 与其他皮肤（默认 / 新中式 / 终端）元素不混用。

## 示例

- 用 `scripts/reskin.py --skin zhongguohong <默认成品.html> -o <输出>.html` 从默认成品生成——本皮肤是纯值替换，reskin 即完整还原
