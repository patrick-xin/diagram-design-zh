# 时间线（Timeline）

**最适合**：发布历史、项目里程碑、事故时间线、路线图、changelog 可视化。

## 布局

- 水平基线横贯中部（`stroke-width=1`，**muted @ 0.50**——比墨色轻一级，是年份水印之上的地平线），**贯通画布 0→1000**：左缘与标题线对齐，轴两端加端点短刻度。
- **跨年时间线用年份大字水印**：每个年份一段 72px mono 600 大字（ink @ 0.05），左对齐放在该年份起点的轴下方背景层，先画水印再画一切事件（事件标签可压在水印上）；年份交界处打刻度 + soft 色 ISO 日期标签（`2026-01`，mono 8px）。单年之内的季度/月份边界才用普通小刻度。
- 时间边界（季度、月份、冲刺）处打刻度，日期标签在下方：纯拉丁 ISO 日期（`2026-03`）用 mono 8px；含汉字（`3 月`）用 sans 12px。
- 事件 = 基线上的实心小圆点（`r=4`）。标签上下交替避免碰撞，用 1px 发丝垂线连到圆点。**上下两侧标签都不溢出画布**：上方事件的日期/名称从 y=12 起排，杆线从标签底连到轴；下方事件同理收在画布内。
- 重大里程碑：**焦点色全套**——垂杆、圆点（`r=6`）、日期字全部 accent，标题保持墨色 600 并放大到 14px（常规事件 12px）。不加光晕圈。
- **时间比例必须诚实**：间隔不相等，圆点间距就不相等（节点 x 按真实时刻线性映射到 0→1000 轴段）。不为美观伪造等距。某段过密就把轴 visibly 断开。
- 事件标签：含汉字 sans 12px；日期与名称分两行（上侧事件自轴向外 = 名称 → 日期；下侧事件 = 日期 → 名称）。
- 图例横条：图例线右缘贯通 0→1000；锚 = 最下内容元素底 + 56（本例最下内容是年份水印 baseline）；口径注右锚 x=1000（`text-anchor="end"`）。

## 反模式

- 时间上不等距的事件画成等距
- 缺轴标签（"这单位是什么？"）
- 标签挤作一团不加垂直错层——不可读
- 每个事件都是焦点色里程碑（重大 = 少数）
- 汉字日期标签 <10px
