# 哑铃图（Dumbbell）

**最适合**：按类目比较同一指标的两个数值，并同时读出变化方向与幅度——改版前后、目标与实际、两个时点的状态。每个类目恰有两个可比数值，且两点之间的距离本身有意义时用。

## 布局惯例

- **一条共享横值轴**：所有类目使用同一线性尺度和单位；刻度、单位与范围清晰可读。不得逐行归一化。百分比等有自然界限的指标显示完整范围；其他指标避免截断坐标轴放大差异。
- **类目列贴画布左缘**：类目标签从 x=0 起排；绘图区在标签列右侧。示例按 1000 宽画布、x=160..960 绘制值轴，左缘与标题及图例对齐。遵循 style-guide「容器对齐与画布基线」的画布规则。
- **每行两个端点**：同一行的空心点与实心点分别表示前值、后值；两点由细线相连。连线在圆周处终止，不穿过圆点；即使后值小于前值，也保持“前空、后实”的身份编码。
- **数值标签**：在两个端点外侧标出原值，并保留同一单位或在轴题统一说明。标签不得盖住端点、连线或相邻行；位置避让时只移动标签，不移动数据点。
- **行数与顺序**：常规画 4–8 类。主要信息是变化幅度时按绝对变化量排序；若类目有自然顺序则保留该顺序。更多类目时先分组或拆图。
- **变化强调**：默认变化用 `ink` 角色及全局透明度梯子表达幅度；负向变化可用 `accent` 提示。方向必须同时由端点位置和数值支持，不能只靠颜色传递。
- **图例**：图例说明空心 / 实心点的含义；若线条深浅编码幅度或使用了负向强调，也一并说明。图例条按 style-guide「图例条」定位。
- **页面**：标准档使用 container 四件套；full 档沿用统一页面级结构。画布高度由内容底与图例条位置按 style-guide 取整。

## 反模式

- 两组以上数值挤在同一行；需要比较多个系列时改用分组点图或其他合适类型。
- 每个类目使用不同坐标范围，或省略刻度和单位。
- 连线穿过端点、后值小于前值时交换空心 / 实心身份，或用箭头替代清晰的端点标记。
- 按正负方向把全图染成两种强色；颜色只作辅助，端点、数值和图例共同承担读数。
- 类目过多仍缩小字号或压缩行距；拆分比挤排更清楚。
