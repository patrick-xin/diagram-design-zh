# UML 类图

**最适合**：对象模型的**静态结构**——类、各自拥有什么、继承什么、 merely 依赖什么。区别性内容是**操作分格**与**类型化关系词汇**（箭头本身带语义）。ER 表达不了这两样——只有当操作或继承 / 组合词汇就是图的论点时用本类型；故事是实体与基数时用 [ER / 数据模型](type-er.md)。

**其他 UML 图——路由别处。** UML 是个家族，这里只给类图立语法：

| UML 图 | 用它代替 |
|---|---|
| 时序 | [时序图](type-sequence.md) |
| 状态机 | [状态机](type-state.md) |
| 组件图 | [架构图](type-architecture.md) |
| 部署图 | [部署图](type-deployment.md) |
| 活动图 | [泳道图](type-swimlane.md) 或 [流程图](type-flowchart.md) |
| 概念 / 领域 ER | [ER / 数据模型](type-er.md) |

## 布局惯例

- 每个类是**单个盒**（`rx=6`，backend 档：纸白 + `ink @ 0.40`），盒内发丝线（`rule @ 0.10`）分隔最多三格，格高随内容——**绝不垫成等高**。
  1. **名格**——类名 sans 12px · 600 居中。接口在名上方挂 `«interface»` 构造型行（mono 8px `accent`）；抽象类类名用斜体（拉丁名）。
  2. **属性格**——每行一条 mono 9px 左对齐：`+ name: Type`。可见性标记：`+` 公有、`-` 私有、`#` 受保护。
  3. **操作格**——每行一条 mono 9px 左对齐：`+ method(arg): Return`。
  某格没有成员就整格省略（无属性的接口跳过属性格）。
- 属性 / 操作写成**单条合并字符串**，不是 ER 的字段 / 类型两列——这个视觉差异让两个类型不打架。
- 标识符（类名、方法签名）**原样不翻译**；说明性文字中文。
- 焦点规则：`accent` 只给正在被实现 / 扩展的那一个类（焦点类 = `accent-tint` 填充 + `accent` 描边）。指向它的**入边继承 / 实现组**合算第二处焦点——全图恰 2 个 accent 元素。

## 关系词汇

六种 marker 全在 `<defs>` 定义、全在图例列出（哪怕图里没用到——图例就是本类型的完整语法参考）：

| 关系 | 线 | 端点（在目标 / 拥有方一端） |
|---|---|---|
| 继承（extends） | 实线 | 大号**空心三角**——`paper` 填充、`ink` 描边 |
| 实现（implements） | 虚线 `5,4` | 同款空心三角 |
| 组合（拥有，级联消亡） | 实线 | **实心菱形**在拥有方一端，`ink` 填充 |
| 聚合（引用，各自独立） | 实线 | **空心菱形**在拥有方一端 |
| 关联 | 实线 | 普通开箭头，**两端**都标多重性 |
| 依赖（uses） | 虚线 `4,3` | 普通开箭头 |

多重性（`1`、`0..*`、`1..*`）mono 8px，离盒边 10–12px，垫纸色遮罩——与 ER 基数标签同一惯例。

## 连线规则

SKILL §8 六条全量适用——正交圆角肘（r=8）、无斜线、不可避免交叉走跳线、共边多边扇出 ≥12px、遮罩标签 6–10px 净空、线画在盒下。布局优先让关系落成直线或单弯；每条边都在跳线的类图已超预算——按包拆。

## 复杂度预算

| 上限 | 规则 |
|---|---|
| 类 | 7（上限不是目标——三格盒密度涨得快，4–5 类是常态） |
| 关系 | 8 |
| 单格成员 | 5（溢出折叠成 mono `…` 一行） |
| accent 元素 | 2（焦点类、其入边实现 / 继承组） |

超预算 → 按包拆两张。

## 反模式

- **getter / setter 列进操作格**——纯噪声，只列要紧的行为。
- **属性方法全量倾倒**——类图是论点不是头文件。
- **组合与聚合混用**——实心菱形意味着部分随整体消亡。说不出口就用空心菱形。
- **关联箭头不带多重性。**
- **没有继承也没有操作时画类图**——那是 ER。
- **构造型书名号到处挂**——只给接口 / 抽象类这些需要它的挂。
- **盒子垫成等高**——格高随内容。
