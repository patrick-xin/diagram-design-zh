# 爆炸轴测图（Exploded axonometric）

**最适合**：一个物体或系统沿一根轴拆开、部件并行投影并标注——设备拆解（手机里有什么）、开箱（盖、产品、内衬、盒）、装配顺序、或把一叠层当作「一件东西的物理零件」展示时用。

**不用它**：有序抽象层各配一行注 → **层级堆叠**（type-layers.md，平文字带，无 footprint 无厚度）；组件与连接 → **架构图**（爆炸图没有箭头，轴上位置是唯一关系）；无序包含 → **嵌套图**；软件跑在哪 → **部署图**。

## 投影

2:1 正二测。地面轴 26.565°，模型单位取 4 的倍数时每条边落整像素。世界 x 向右下、y 向左下、z 向上。每个点用同一个函数投影，绝不手摆坐标：

```python
def iso(x, y, z, ox, oy):
    """模型点 → SVG 点。(ox, oy) 是模型 (0,0,0) 的落点。"""
    return ox + x - y, oy + (x + y) / 2 - z
```

圆角矩形 footprint（圆角 r）投影为直边 + 四段同一椭圆的四分之一弧（`rx = r·√2`、`ry = r/√2`）。一个形状通吃：`r=0` 是方盒/板、小 `r` 是产品圆角、`r = w/2 = d/2` 是圆柱。内缩轮廓时角心不动，内缘 = 同四心更小半径。

面画成普通 `<path>`/`<polygon>`，投影点写死在 d 里。不用 CSS 3D、不用 canvas/WebGL、不用 `transform` 摆几何。内容需要平贴在面上时，与 `iso()` 相配的矩阵：顶面 `matrix(1,0.5,-1,0.5,tx,ty)`、左面 `matrix(1,0.5,0,-1,tx,ty)`、右面 `matrix(-1,0.5,0,-1,tx,ty)`——**标签永不用矩阵，标签保持水平**。

## 布局惯例

- **部件 2–5 个，自下而上列**。每件是一个圆角棱柱（rect + 厚度 t），顶面至多两级细节——顶面是读者看到的面。
- **爆炸轴竖直为默认**：部件直上、不旋转、最底部件留在 z=0。组装时并排的部件共享一层、一起抬升（手机的板与电池同层，不叠两个间隙）。
- **间隙**：相邻层间一个 gap，`gap = max(k×顶面高, 3×最厚实体厚度)` 上取整到 4 的倍数；`k=0.5` 为下限，高的部件会挡住下方焦点件时提到 0.75。顶面高 = 最大 footprint 的 `(w+d)/2`。容器（外壳、盒）不计厚度。
- **避让**：引线会穿过部件、或两标签近于 36px 时，gap 按 4 步进抬高直到都不发生。同层两件相撞调 plan 位置，不是调 gap。
- **绘制序**：底层先画；层内 x+y 小的（更靠后）先画；容器拆两半——后半（轮廓、内缘、腔、底）先于腔内部件、外壁与前缘后画。组装态框架要能看见托盘里的部件，只有这个顺序做得到，且爆炸全程保持正确。
- **画布**：1000 宽，物体与 240px 标签列一起居中；viewBox 高随爆炸态物体 + 40px 顶边距。

## 面上色（浅色档）

| 元素 | 值 |
|---|---|
| 面基（每面下先铺的不透明底） | `#ffffff` |
| 顶面 | 基色 |
| 左面（受光侧） | 基 + `ink@0.07` |
| 右面（背光侧） | 基 + `ink@0.15` |
| 焦点件三面 | 顶/左/右 = 基上 `accent@0.10 / 0.20 / 0.30`（闭集取档） |
| 轮廓 | `ink` 1.2 |
| 内棱（顶前缘、前角） | `ink@0.50` 0.8 |
| 面上细节线 | `ink@0.50` 0.6–0.8 |
| 腔内壁（外壳/盒的内腔壁面） | 基 + `ink@0.10`（深色 tint 档） |
| 腔内底（内腔深处的底面） | 基 + `ink@0.05` |
| 内衬切口（模塑件的开孔） | 基 + `ink@0.15` |
| 吊线（trace） | `ink@0.30` 0.8 虚线 `4,3` |

光从左上来，左面亮于右面。**永远要上面色明暗**：只有轮廓的盒子会在两种读法间翻转（Necker 错觉）。面 = 不透明基 + ink 覆盖，绝不用半透明填充单独承担——后面的件会透出来。吊线从最底部件轮廓的左右极点直上到顶部件底面，先于一切部件绘制（部件盖住它）。

## 标签

- 每件一签，物体右侧一列。签 = 件名（sans 600，一两个词）在上、技术副题（mono、`muted`）在下；含汉字的副题 10px 起。
- 水平引线（0.8、`ink@0.40`）从部件右极点中厚处 2px 圆点旁 6px 起，到标签列左 12px 止。引线不折弯、不穿件、互不交叉——不同高度的水平引线天然不交，间隙规则保证它们避开部件。
- 焦点件的圆点、引线、副题取 accent，件名保持 ink。不用编号注记、不用图例——标签就贴在它命名的部件上。

## 细节与焦点

- 至多三级：形态（圆角棱柱）→ 顶面内嵌（屏幕、腔 outline、模压槽）→ 微细节（芯片、镜头、logo）。内嵌可能触到面边的 clip 到该面内并离边 ≥4 单位，三级封顶。**无接触阴影**——本皮肤禁阴影；需要落地感时最底部件本身就是地面。
- **焦点件至多一件着 accent**，其余保持中性，**不用透明度淡其他件**——半透明的件会透出后面的边。

## 可选动效

爆炸图可以从组装态开场、爆炸一次——看部件升起就是在看它们怎么装回去。控制器用 `assets/template-motion.html` 的 reveal 模式（逐字节锁，见 animation.md）：部件组带 `--lift` 变量做一次 `translateY`（此投影里模型竖直上移就是屏幕竖直上移）；底层不动、其标签与吊线最后一步到位；各件标签在组装态隐藏、该件落定后淡入（隐藏要即时、只延后显现，否则前半秒标签堆在闭合体上）；无 JS、`prefers-reduced-motion`、打印、`?motion=static` 与导出都呈现爆炸帧。竖直抬升是动效位移上限的唯一有记录例外，别的什么都不动。

## 诚实数据

部件的 footprint、厚度、层号与间隙由一套声明推算再投影复核（每个部件声明其盒、z、厚度与层；轮廓、吊线、标签各司其职）——手摆坐标、transform 顶替几何、或部件声明与绘制不一致都是这一型的谎话。

## 反模式

- 手摆坐标，或 CSS `transform` 顶替几何。
- 只有轮廓没有面色的部件。
- 部件旋转、横移、或一图两轴爆炸。
- 间隙不均、或为塞进画布缩 gap（提 k 或砍一件）。
- 标签贴在部件上、随面倾斜、或散成两列。
- 编号注记 + 底下钥匙。
- 一件以上 accent，或淡其他部件来突出重点。
- 模糊接触阴影、实面渐变、发光。
- 对没有「物理零件感」的东西做爆炸图——层只是一串清单时用层级堆叠。
