# 品牌接入（onboarding）

把用户的品牌色与字体提取出来，写入 `style-guide.md` 的语义角色。只在用户明确选择定制时执行；**写入前必须先给出旧值→新值的 diff 提案，用户确认后才动文件**。

## (a) 从网站 URL 提取

1. 抓取首页 + 一两个关键子页的 HTML/CSS。
2. 提取：主色、辅色、背景色（CSS 变量、`meta theme-color`、logo 用色）、标题字体、正文字体。
3. 映射到语义角色：
   - 背景最浅色 → `paper`
   - 最深文本色 → `ink`
   - 最具辨识度的品牌色 → `accent`（**只取一个**；品牌有多个色时选焦点色，其余降为 muted 变体）
   - 无明确链接蓝 → 保留默认 `link`
4. 字体：品牌拉丁字体接入对应栈首位，中文回退与系统兜底**原样保留**（三栈结构不许破坏）。
5. 输出 diff 提案（角色 | 旧值 | 新值 表格），确认后写回。

## (b) 从截图 / 海报 / PPT 页提取

1. 读图，提取三类色：背景、主文本、强调色；判断字体气质（衬线 / 无衬线）。
2. 同上映射。**对比度必须实算**：`ink`、`muted` 对 `paper` 达 AA；`accent` 作描边 ≥3:1、作文本 ≥AA——不达标就把该色加深/减浅一档再提案，不允许"看着差不多"。

## (c) 从本地文件夹提取

1. 扫描给定路径下 CSS / JSON / Markdown 里的颜色与字体变量。
2. 同上映射 + diff 提案。

## (d) 手动

用户直接给 hex → 过对比度检查 → diff 提案 → 写回；给字体名 → 走「字体接入」节。

## 字体接入

1. 字体来源可以是已装字体、用户文件或用户指定的下载来源；不确定就说明。用 `python3 <技能目录>/scripts/embed_fonts.py --inspect-font 字体文件` 读内部 family、字重和合集索引，**不以文件名或下载元数据猜 family**。文件在手无需装系统。
2. 按用途接 sans（正文/节点）、serif（标题/旁注）或 mono（技术串）；只换所选栈首位，保留 CJK 与系统回退。拉丁品牌字体可以加入首位，缺中文字形由内嵌思源回退。用户已说“通篇/只正文/只标题”时照做；作用范围影响结果且无法推断时才问。
3. 现有成品先改 `:root` 对应栈，再运行：

   ```bash
   python3 <技能目录>/scripts/embed_fonts.py 图.html --font 字体文件
   ```

   可重复 `--font` 给多字重或多族文件。脚本把 SVG 对应角色的**字面栈同步**到根变量，必要时补回被首位替换掉的思源族引用（例如 serif 栈），其余回退顺序保留；保持几何、字号、id/aria 和颜色，这是换字体必需的一步。新成品同样运行。不要手工塞 base64。
4. 脚本按 family 精确匹配所有可用正体字重；未匹配不会冒用第一份文件。已装字体从用户/共享目录递归发现，支持 ttf/otf/woff/woff2/ttc/otc，变量字重 face 保留其范围。系统字体按脚本的排除策略不随图分发。
5. 自定义 face 与包内思源回退同时携带。单字重字体可能由浏览器合成缺失字重；缺字/缺文件见 ⚠ 就说明实际回退。随图分发需可再分发的字体，不能因本机已安装就断言可以再分发。
6. 换字体后浏览器检查标题、SVG 节点、技术标签和中文回退是否真的命中新栈，有无宽度溢出。不能仅凭脚本成功或 self_check 绿判断字体已生效。需要布局适配时先说明，不把纯换字体顺手变成重画。

换回默认 = 所选栈回生效默认三栈 + 重跑内嵌/同步，恢复的是字体设置，不回滚用户的颜色或其他内容。内嵌保障覆盖字形的字体随文件分发；系统首选字体、集外字和不同渲染器不保证跨机逐像素一致。

## 写回与约束

- 只写 `style-guide.md` 的 token 表与字体栈（字体流程见「字体接入」节），保持语义角色结构与三栈结构不变。
- 不可破坏的约束：WCAG AA、一个 accent、无彩虹（品牌 8 色也只取 paper / ink / accent 三主色 + 派生）、三栈纪律、背景不纯白。
- 新中式皮肤不受品牌定制影响（自带完整色板，见 `skin-xinzhongshi.md`）。
- 写回后本项目的后续图全部继承，不再重复问。
- 写回完成后提议把这份皮肤 `save` 成命名档案（一台机器服务多品牌，见 [`profiles.md`](profiles.md)）；单品牌用户可不存，工作副本继承照旧。

## 反模式

- 不给 diff 直接改文件——用户必须看到改了什么
- 提取到的颜色全塞进去——超过三个主色就是彩虹
- 纯白背景、删系统字体兜底
- 用品牌色覆盖 `link` 之外的语义角色乱点鸳鸯谱
- 不读字体 name 表就落栈首位——family 名写错静默回落
- 手工 base64 字体塞进 `<style>`——内嵌统一走 embed_fonts（标记区外的手工块不参与幂等重建）
