# diagram-design-zh

agent 零指令产出中文图表的技能：中文字体、字号、字距、混排规则全部内置，产出单文件、断网可开的 standalone HTML。

基于 Cathryn Lavery 的 [diagram-design](https://github.com/cathrynlavery/diagram-design)（MIT）改造。

## 安装

```bash
git clone https://github.com/patrick-xin/diagram-design-zh ~/.claude/skills/diagram-design-zh
```

装完直接对 agent 说「帮我画一张微服务架构图」即可。35 个示例在 `assets/`，浏览器打开即看。

MIT。图标与字体的第三方许可见 [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md)。
