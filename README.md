# diagram-design-zh：agent 零指令产出中文图表的技能

**标准中文图表，白底、正式场合直接可用。**

> 本项目 fork 自 [Cathryn Lavery](https://github.com/cathrynlavery) 的 [diagram-design](https://github.com/cathrynlavery/diagram-design)（MIT）。设计系统的骨架来自原项目；中文排版层的重写，以及「本项目独创」的全部能力，由本仓库完成。

## 项目简介

对 agent 说一句「帮我画一张微服务架构图」，得到一张**单文件、白底、到手就能用**的 standalone HTML 图表——中文字体、字号、字距、中英混排规则全部内置。

不用再教字体。不用再调字号。不用再修间距。

适合谁：

- 用 agent 干活的开发者，经常要画架构图、时序图、数据流
- 要把图贴进周报、汇报文档、公众号文章的工程师和写作者
- 有品牌色要求的乙方 / 多客户团队（品牌档案，多客户互不串色）

## 为什么需要中文版

原版是一套英文设计系统，直接拿来画中文有三个硬伤，本仓库为此重写了整个排版层：

1. **字体**：原版用 Geist / Instrument Serif，没有中文字形，且依赖 Google Fonts 外链——国内拉不到。本仓库换成思源三字体栈（宋体标题 / 黑体节点 / Sarasa 等宽技术标签），成稿自动内嵌字体子集，断网打开像素级一致。
2. **字号**：原版按拉丁微缩字号设计（9px / 7px 标签），中文笔画密集，这个尺寸不可读。本仓库立了含汉字 ≥10px 的硬线，字号坡道按国内正文惯例校准（节点名 14px、中文小字 12px），并有自检脚本逐字强制。
3. **排版**：中英混排空格、全角标点、角标字距这些中文语域规则，原版没有概念。本仓库把它们全部写成硬规则，违反即不交付。

## 本项目的独创

- **reskin 换肤机器**：一张皮肤就是一张「语义槽位 → 色值」的表（十几行 JSON）。对任何成品 HTML 做值级替换——透明度档位结构原样保留、只换基色；领域语义色（安全 / 可观测 / 治理 / 备份 / 工作区）跨皮肤恒定，**换皮不换义**。皮肤表自带质量门：对比度 AA、焦点色唯一、防彩虹。同一张图要出政务红版、新中式版，一条命令。
- **self_check 质量门**：五层可执行自检——单文件契约（零远程引用）、无障碍契约、动效逐字节校验、中文排版硬规则、几何网格。不是「请检查」的清单，是跑不过就不交付的脚本。
- **字体内嵌交付**：成稿自动切 GB2312 子集、以 data: URI 内嵌进单文件——图默认要分发，必须断网可开。
- **颜色值集闭集**：全库颜色只许四个合法出处（token / 透明度梯子 / 系列色 / 语义色族），透明度只取标准档位——色值漂移在制度上被禁止，换肤才不漏色。
- **中文平台预设**：公众号封面 900×380（@2 出 1800×760）、小红书 3:4 1080×1440——按预设尺寸重画，不缩放，agent 不许心算。
- **国内品牌图标**：华为、知乎、支付宝、微信、哔哩哔哩、字节跳动、TiDB、RocketMQ 等，单色 currentColor 管线，许可逐枚可溯。

## 安装

方法一：克隆到技能目录（推荐，用户级全局可用）

```bash
git clone https://github.com/patrick-xin/diagram-design-zh ~/.claude/skills/diagram-design-zh
```

方法二：项目级（随仓库走，不污染其他项目）

```bash
git clone https://github.com/patrick-xin/diagram-design-zh <你的项目>/.claude/skills/diagram-design-zh
```

验证安装：对 agent 说「帮我画一张微服务架构图」；或直接用浏览器打开 `assets/example-architecture.html` 看锚点示例。

## 使用

### 基础用法

装完直接和 agent 说：

- 「画一张电商系统的架构图」
- 「把这段时序画出来：用户 → 网关 → 订单服务 → 库存」
- 「把这个 Mermaid 文件重画成设计稿」——Mermaid / draw.io 文件导入后按设计系统**重绘**（不是渲染），附保真台账
- 「出一张公众号封面尺寸的飞轮图」——平台预设按尺寸重画，不缩放

### 效果预览

每个类型都有中文锚点示例，在 `assets/`，浏览器打开即看。产出是零依赖单文件 HTML——直接发人、贴文档、断网打开像素一致。

## 能力总览

- **图表类型**：架构 / 流程 / 数据流 / 时序 / 状态机 / ER / 泳道 / 甘特 / 柱状 / 折线 / 散点 / 雷达 / 树 / 组织图 / 嵌套 / 分层 / 象限 / 飞轮 / 金字塔 / 矩形树图 / 韦恩 / 高层架构 / 徽章 / IT 现状 / 数据产品集成 / 安全矩阵 / 时间线 / 循环——完整清单见 `SKILL.md` §3 路由表
- **语义模式先行路由**：排队瓶颈 / 阶段框架 / 结构化产物 / 策略评估 / 安全铺路 / 治理清单 / 补偿分层——载荷重的题先选模式再选类型
- **导入重绘**：Mermaid 源与 draw.io 文件 → 结构摘要 → 按设计系统重绘
- **输出**：standalone HTML（默认）/ PNG @1/@2 / SVG / 透明底
- **品牌档案**：从网站 / 截图 / 设计文件提取品牌色写入档案，一套安装服务多个品牌客户，互不串色
- **可选增强层**（默认全不启用）：无障碍分步动效 · 单色图标库（含国内品牌）· 深色档 · 终端皮肤 · 编辑旁注 · 手绘滤镜

## 文件说明

- `SKILL.md` — 技能入口与调度
- `references/` — 全部规则文档（style-guide.md 是颜色唯一权威）
- `assets/` — 各类型中文锚点示例 + 模板（深色 / 终端 / 动效）+ 图标页
- `scripts/` — self_check / embed_fonts / reskin 与导入提取器
- `fonts/` — 内嵌字体母本（思源 GB2312 子集，OFL）
