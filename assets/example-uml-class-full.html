焦点

恰好 2 个：焦点类 + 实现边组

正在被实现 / 扩展的类走焦点处理（accent-tint 底 + accent 描边）；指向它的全部继承 / 实现边合算另一处焦点。其余类盒一律 backend 档。

读法

箭头即语义：六种关系词

  • 三角 = 继承 / 实现（实线 vs 虚线 5,4）
  • 菱形 = 组合（实）/ 聚合（空），标在拥有方
  • 开箭头 = 关联（带多重性）/ 依赖（虚线 4,3）

口径

没有操作也没有继承就别用类图

类图讲的是操作分格与类型化关系词汇——那是它比 ER 多说的话。故事是实体与基数就用 ER；getter / setter 是噪声，类图是论点不是头文件。
