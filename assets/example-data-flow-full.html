四个角色在五步管道中交接数据：管理员定权限，工程师采集加工，分析师建模发布，使用者只读消费。

探索建模 · 唯一焦点节点

焦点节点芯片 accent 填充、步骤头数字与名同色；全图恰好一条 accent 跨角色交接——工程师 → 分析师，标注「匿名数据」。

读法

左入右出 · 芯片码字

  • 节点进左缘、出右缘——载荷流向不靠箭头猜
  • 节点上下芯片是数据类型码字（mono 反白），进 = 上、出 = 下
  • 四角色五步：管 / 工 / 析 / 用各占一行，跨行即跨角色

口径

泳道 vs 数据流

跨部门业务流程用泳道；带类型化载荷与角色边界的数据管道才用数据流。五种载荷：流 → 集 → 表 → 报 → 视图。
