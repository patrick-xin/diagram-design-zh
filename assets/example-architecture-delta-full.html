订单履约：改造前与改造后

焦点

变更只有一处着色：订单服务升 v2

accent 淡染与左缘竖条只落在升 v2 的订单服务上——它是唯一改了实现的组件。队列是新组件、worker 只挪位置、派单器是删除：三种状态各有记号，不共享 accent。

读法

先看台账，再对快照

  • 中栏台账是入口：七处变更各带编号与目标 ID
  • 左右快照的组件角标（= + − ~ ↔）与台账一一对应
  • 「保持不变」区点名未动项——改造没碰的东西同样要说清

口径

ID 跨快照不变

同一对象在两栏用同一 ID（api、worker、r2），读者才能逐项对号。虚线与点线编码的是变更状态，不编码协议——协议写在关系标签上（HTTPS、SQL）。示意架构。
