数据平台集成拓扑

三个源系统接入数据平台、三个消费面对外取数：对象存储与查询引擎两个焦点面承载并供给数据，调度、身份、日志横切整个平台层。

焦点

恰好两个焦点组件

焦点条高 56、accent 淡染 + 描边；非焦点条高 44、ink 中性——缺省取存储枢纽与联邦引擎，这两个面把「平台」与「工具堆」区分开。

读法

bar + row · 底条

  • 横条 = 整分区宽（bar），行节点沿分区宽均布（row），底条垫分区下方全宽
  • 源 / 消费按 type 映射图标：JDBC · CSV · EVENTS 入，JDBC · 内核 · HTTPS 出
  • 调度器以触发线驱动两个焦点组件

口径

AUTH 线 · 连层不连组件

横切服务（统一身份、集中日志）以 AUTH 线接入整个平台层——范围是全层而非某个工具；分区标签住顶部边框断口遮罩。
