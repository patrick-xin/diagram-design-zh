支付网关块分解

焦点

根块承担端到端责任

accent 只落在根块 PAY-001——网关对每笔交易负责到底：每笔交易恰好落进一个终态。三个子块保持中性，各自管好一段。

读法

层级 × 稳定 ID × 输入输出

  • 根在第 0 层、三块子分解在第 1 层，直角肘线只表从属
  • 每块带稳定 ID 芯片（PAY-001-01 式），改名不改 ID
  • 块内一行摘要写「输入 → 输出」

口径

元数据即契约，图外可追溯

每块除可见文字外还声明输入/输出/约束/假设与实现路径（如 src/payments/authorization/）。约束示例：卡授权绝不落盘原始卡号；台账只追加、不改写已写入的行。
